EVIA Paradigma 是一款視覺化程式設計工具，適合想了解機器實際接收內容的人。圖表就是程式，語言只是一項設定。在畫布上連接程式方塊並執行，接著選擇產生目標：使用 Clang 或 GCC 的 C99 至 C++20、Python 3、Java 或 Kotlin 程式、Android 應用程式、Arduino 草圖、適用於 AVR、PIC32 或 STM32 晶片的裸機 C，或用於 FPGA 的 SystemVerilog、Verilog 或 VHDL。

下載 EVIA 0.12.1 在 GitHub 上檢視原始碼

支援 Windows、macOS 和 Linux。免費開放原始碼，採用 MIT 授權。

功能介紹

程式由方塊和連線組成

Start、Set、Input、Print、If/Else、For、While 和 Do-While 都是程式方塊；它們之間的連線表示控制流程。按下 Run，正在執行的程式方塊會反白顯示。運算式支援數字和文字、&& || !、比較運算及一般算術運算。

類別、物件和模組

類別包含具有初始值的欄位、建構函式和方法；每個方法都是從 Enter 到 Exit 的獨立程式方塊圖。每個 Exit 都會成為呼叫方塊的輸出。使用相同物件名稱的方塊會共用同一個物件。將類別儲存為模組（.eviam）並匯入其他程式。

一個圖表，十九種語言

圖表描述程式的功能，而不是它使用的語言。同一畫布可產生八種 C 和 C++ 標準、Python 3、Java、Kotlin、Android 應用程式、Arduino 草圖、裸機 AVR、PIC32 或 STM32 C，或用於 FPGA 的 SystemVerilog、Verilog-2001 和 VHDL。Run 會直接執行圖表本身，因此你可以將輸出與任何產生版本比較。如果目標不支援某個方塊，錯誤會指出該方塊，而不會悄悄改變程式含意。

八種 C 和 C++ 標準，兩種撰寫方式

在工具列中選擇 C99、C11、C17、C++98、C++11、C++14、C++17 或 C++20。Structured 會產生 if/else、迴圈和 switch；Goto 會將每個方塊轉換為標籤，並將每條連線轉換為跳躍。Safe 數值保留文字及直譯器的所有檢查；Fast 數值是沒有執行階段檢查的一般 double。C 執行階段僅包含程式實際使用的部分，因此可透過 -Wall -Wextra -Wpedantic -Werror 嚴格編譯。

Python 3，無需編譯

選擇 Python 3，同一圖表就會產生一個 .py 檔案，可在 Python 3.8 或更新版本上執行，無需任何套件或編譯器。類別會變成 Python 類別，程式變數會變成模組全域變數；程式碼視窗中的 Run 會啟動程式，在 Input 中輸入的文字會傳給程式。Python 沒有 goto，因此 Structured 會寫出 if/else 和 while 迴圈，Goto 則變成每個方塊一個分支的小型狀態機。Print、Input、數字文字以及所有錯誤訊息都與直譯器完全一致。

檢視任何方塊的程式碼

在方塊上按右鍵並選擇 View source code：產生的檔案會開啟，並精確反白該方塊對應的程式碼行。也可檢視整個方法或類別，並支援所選的任何語言。Compile & Run 會直接使用 Clang 或 GCC 編譯；在 Windows 上，應用程式會自動安裝 llvm-mingw 或 WinLibs GCC，不需要 Visual Studio。

Arduino 和 ESP32 開發板

Pin Mode、Digital Write and Read、Analog Read and Write、Delay 和 Millis 也都是方塊。同一個 Arduino 草圖可用於 Uno、Nano、Mega 2560、Leonardo、Micro、Pro Mini，以及 ESP32、ESP32-S2、-S3、-C3、-C6 和 -H2。UART、SPI、I2C 與 MQTT 同樣是積木。Run 會在電腦上模擬 Uno，並在輸出中顯示每次接腳變化，讓你在接上開發板前先測試程式。

深入暫存器的裸機程式設計

AVR C 可為 ATmega328P、ATmega2560 或 ATmega32U4 撰寫不依賴 Arduino 核心程式庫的程式：以易讀的 C 設定連接埠、計時器、PWM、ADC 和 UART。avr-gcc 可將程式編譯至約 4 KB，Upload 會透過 avrdude 將程式寫入開發板。每個範例都會在 simavr 模擬器中執行，並與直譯器比對。

0.5 新增：PIC32 C 使用 Microchip XC32 為九款 PIC32MX 晶片提供相同功能；UART、SPI 和 I2C 也成為 Run 和全部三種開發板語言中的方塊。PIC32 程式碼已根據 Microchip 裝置標頭檔檢查，但尚未使用 XC32 編譯或在晶片上執行。

0.6 新增：FPGA 支援。SystemVerilog、Verilog-2001 和 VHDL 可將同一圖表轉換為適用於 Artix-7（Nexys A7、Arty A7、Basys 3）和 Cologne Chip GateMate 開發板的硬體。輸出會與 Run 的結果進行模擬比對，並使用開放原始碼工具合成；目前尚未透過 Vivado 或載入開發板。

0.6.5 新增：MQTT。五個積木把程式的數字發布給代理伺服器並讀回命令：UART2 接 WiFi 模組的 PIC32MX、自帶 WiFi 的 ESP32，以及對著你電腦上代理伺服器執行的 Run。產生的用戶端對著真實代理伺服器檢查過，但沒有 WiFi 模組或晶片參與。隨附兩個範例，其中一個用於 PIC32 Ethernet Starter Kit II。0.6.7 新增：在 MX695、MX795 和入門套件上，MQTT 還可以從晶片自帶的以太網路埠出去，產生的檔案成為 MPLAB X Harmony 專案的應用程式；這是實驗性的，尚未用真正的 Harmony 建置過。介面本身也可在設定中選擇英語、俄語或亞美尼亞語。

0.6.9 新增：Python 3。同一圖表會產生一個 .py 檔案，可在 Python 3.8 或更新版本上執行，無需安裝其他內容；程式碼視窗中的 Run 會直接啟動它。其輸出、錯誤和結束代碼都與直譯器一致，和每種 C 與 C++ 標準一樣。

0.7.0 新增：設定移到了 File 選單中，每個裝置系列各有一頁——一般、C、C++ 和 Python、Arduino、ESP32、AVR C、PIC32 和 FPGA；Open Example 也分成了 Arduino、ESP32 和 PIC32 子選單，開啟範例時會同時選好對應的語言和開發板。

0.8.0 新增：安裝程式自帶工具鏈——avr-gcc 和 avrdude，以及用於 FPGA 的 OSS CAD Suite——因此裸機 AVR C 和 FPGA 流程無需任何設定即可使用。Microchip 的免費 XC32 可直接在應用程式中安裝（Settings、PIC32、Get XC32），直接從 microchip.com 取得。Settings 和 Devices 現在是獨立的選單。

0.7.1 新增：除 .deb 之外，還有適用於任意 x86-64 Linux 的 AppImage——一個內含 Java 執行環境的執行檔，無需安裝，也不需要 root。板上程式可用的模組（UART、SPI、I2C 和 MQTT）在上面有說明。

New in 0.9.0: STM32. The Blue Pill, Black Pill, Nucleo-F401RE, Nucleo-F411RE and STM32F4DISCOVERY take the same diagrams as bare-metal STM32 C (registers only, its own start-up code and linker script) or as Arduino sketches with STMicroelectronics' core, and Upload sends them through an ST-Link with OpenOCD. The installers are now small online installers: the toolchains — arduino-cli, avr-gcc, the Arm GNU Toolchain, OpenOCD and the OSS CAD Suite — are packages of the EVIA server, picked on the first start and updated in place from Settings, Packages and Updates, and the application updates itself the same way. The STM32 code is built with arm-none-eabi-gcc and run in QEMU in CI, but has not yet been run on a board.

0.10.0 新增：Java、Kotlin 和 Android。同一圖表可產生 Java 或 Kotlin 程式，直接在程式碼視窗中編譯執行；也可產生 Android 應用程式，EVIA Paradigma 不需 Gradle 即可建置，並透過 USB 安裝到手機上。JDK 和 Kotlin 編譯器是 EVIA 伺服器的套件；Android SDK 在你接受其授權後從 Google 下載。

0.10.1 新增：手機感測器。Phone Sensor 方塊可讀取 Android 手機的加速度計、陀螺儀和 GPS，Run 會模擬它們。File → Open Example → Android Phones 中有三個入門應用程式：Hello world、GPS 座標檢視器和動作測試器。

0.11.0 新增：原生可執行程式。EVIA Paradigma 自帶的編譯器可將方塊直接轉換為 Linux x86-64 程式，電腦上不需編譯器、組譯器或連結器，程式的行為與 Run 完全一致。EVIA Paradigma Native 是以它為核心的第二個應用程式：不產生程式碼，只有 Build executable 和 Run executable。

板上程式可用的模組

UART 在所選埠上收發位元組或整行，在板子上也是 Print 的輸出去處。SPI 以主機方式傳輸一個位元組或一段緩衝區，模式與時脈由你選擇，每個裝置可指定各自的晶片選擇腳。I2C 按裝置位址讀寫暫存器，大多數感測器就是這樣驅動的。MQTT 是五個區塊——Connect、Publish、Subscribe、Has Message、Read——把程式的數值送到代理並取回命令，走 UART2 上的 WiFi 模組、ESP32 自帶的 WiFi，或 PIC32 自己的以太網路埠（作為 Harmony 應用程式）。每個模組都是調色盤裡的一個區塊，而不是需要安裝的程式庫；在 Run 中與在晶片上行為一致；在不支援它的目標上會指名拒絕，而不是產生一段默默無法運作的程式碼。

專案、Git 和 GitHub

File, New Project 會建立一個包含程式、模組資料夾、README 和 Git 儲存庫的資料夾。Git 選單中可執行 Commit、push 和 pull；Connect to GitHub 會使用 Git 既有的登入資訊發佈專案。應用程式不會索取或儲存密碼。

  • 隨處使用 Vim。程式碼欄位、程式碼視窗和提交訊息均支援 Vim 按鍵；Edit in Vim 會開啟真正的 Vim。
  • 命令列。 evia --run program.evia 和 evia --gen program.evia --lang c11 -o program.c 可用於指令碼和 Makefile。
  • 自動找到 Python。 Settings, Python 無需設定即可使用 python3 或 Windows 上的 py 啟動器；Check 會顯示版本。
  • Clang 或 GCC。可在 Settings 中切換；Windows 會自動安裝所選編譯器，不需要 Visual Studio。
  • 深色模式。應用程式採用類似 IntelliJ IDEA 的外觀，並使用 Inter 和 JetBrains Mono 字型。View、Theme 可選擇淺色、深色或系統主題。
  • 內建指南。Help、Guide（F1）提供英文、俄文和亞美尼亞文版本，說明各方塊、運算式、類別功能、快速鍵和 Vim 按鍵。
  • PDF 教學。 Help, Tutorial 可用七種語言中的任一種開啟完整教學。
  • 設定會下載工具。 arduino-cli、avr-gcc 與 FPGA 套件會下載到應用程式自己的資料夾；XC32 會開啟 Microchip 的頁面。

八步完成第一個程式

完整教學包含所有螢幕擷圖，提供七種語言的 PDF：English、Русский、Հայերեն、Deutsch、简体中文、繁體中文、日本語。也可在應用程式的 Help、Tutorial 中查看，或閱讀 README。

  1. 建立專案

    File、New Project。保持勾選 Create a Git repository。

  2. 建立迴圈

    將 Set、For 和 Print 拖曳到畫布上，連接它們並按 Run。

  3. 建立類別

    Edit、New Class：為 Counter 新增 total 和 calls 欄位。

  4. 使用類別

    將 Counter.add(x) 拖曳到迴圈中，並將物件命名為 c。

  5. 檢視程式碼

    在方塊上按右鍵並選擇 View source code。

  6. 選擇語言

    切換到 C11 或任一 C++ 標準，程式碼會重新產生。

  7. 提交並發佈

    選擇 Git、Commit，接著選擇 Connect to GitHub。

  8. 繼續探索

    模組、範例和指南（F1）。

四步完成第一個 Python 程式

任何圖表都能作為 Python 執行。只需要來自 python.org 的 Python 3.8 或更新版本，EVIA Paradigma 會自動找到它。

  1. 選擇 Python 3

    在工具列或程式碼視窗的 Language 清單中選擇 Python 3。

  2. 產生 Python 程式碼

    按 F7。在方塊上按右鍵並選擇 View source code，即可查看它產生的程式碼行。

  3. 在程式碼視窗中執行

    按 Run。在 Input 中輸入的文字會傳給程式，出錯時程式會停止，並顯示與編輯器中相同的訊息。

  4. 儲存 .py 檔案

    Save 會寫出該檔案，它可以在任何地方用 python3 program.py 執行。

java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang python -o tutorial.py
python3 tutorial.py
# goto flow and fast values work too
java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang python --flow goto --values fast -o tutorial.py

Settings, Python 中保存執行命令：python3、Windows 上的 py 啟動器或完整路徑。Detect 會重新尋找，Check 會顯示版本。

四步完成 Java、Kotlin 和 Android 應用程式

同一圖表可以產生 Java 或 Kotlin 程式，也可以產生 Android 手機應用程式。設定中一鍵即可取得 JDK 和 Kotlin 編譯器；接受授權後，Android SDK 會從 Google 下載。

  1. 選擇 Java、Kotlin 或 Android

    在工具列或程式碼視窗的 Language 清單中選擇，然後按 F7 檢視程式碼。

  2. 編譯並執行

    對於 Java 和 Kotlin，在程式碼視窗中按 Compile & Run。在 Input 中輸入的文字會傳給程式。

  3. 建置 Android 應用程式

    Build 使用 Android SDK 本身的工具在幾秒內產生 APK，不需 Gradle 或 Android Studio。該資料夾仍可在 Android Studio 中開啟。

  4. 安裝到手機

    開啟 USB 偵錯，連接手機並按 Install on Phone。應用程式會自動啟動：Print 顯示在螢幕上，Input 在文字欄位中輸入。

java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang java -o Program.java
java Program.java
java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang kotlin -o tutorial.kt
java -jar evia-paradigma.jar --android examples/tutorial.evia ~/apps/tutorial --install

Settings 的 Java and Kotlin 頁面設定 JDK 和 kotlinc；Android 頁面設定 SDK、應用程式的 ID 和名稱以及手機。Java 和 Kotlin 的輸出在 CI 中與直譯器一致；應用程式已在電腦上檢查，但尚未在手機上執行過。

四步完成第一個 FPGA 程式

同一個 blink 圖表可轉換為適用於 Artix-7 和 GateMate 開發板的硬體。完整教學的第 10 步見上方 PDF，指南中也有 FPGA 主題（F1）。

  1. 選擇語言和開發板

    語言：SystemVerilog、Verilog-2001 或 VHDL。開發板：Nexys A7、Arty A7、Basys 3 或 GateMate。

  2. 開啟 Blink 範例

    File、Open Example、FPGA Boards、Blink。接腳名稱範例：LED0、SW3、BTNC 和 JA1。

  3. 產生程式碼

    按 F7。接腳限制位於第一則註解中，命令列會將其寫入獨立檔案。

  4. 建置並上傳

    在 Settings 中選擇 Vivado 或開放原始碼工具。Upload 會對開發板進行程式設計。

java -jar evia-paradigma.jar --gen examples/fpga/blink.evia --lang sv --board nexys-a7-100t -o blink.sv
# writes blink.sv and blink.xdc
java -jar evia-paradigma.jar --gen examples/fpga/blink.evia --lang vhdl --board olimex-gatemate -o blink.vhd
# writes blink.vhd and blink.ccf

已在模擬中與直譯器比對，並使用開放原始碼工具合成。尚未透過 Vivado 執行或載入實體開發板。
