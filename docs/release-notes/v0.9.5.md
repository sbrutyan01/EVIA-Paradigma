# EVIA Paradigma 0.9.5

Two more boards: the **chipKIT Pro MX7** (PIC32 C) and the **32F429IDISCOVERY** (STM32 C and Arduino). An update
package: 0.9.0 to 0.9.4 take it from **Settings → Packages and Updates…** and start 0.9.5 the next time.

## chipKIT Pro MX7 (PIC32 C)

Digilent's chipKIT Pro MX7, formerly the Cerebot MX7cK: a **PIC32MX795F512L** with four LEDs, three buttons, a
USB-UART and an Ethernet PHY.

- `LED_BUILTIN` is **LD1 (RG12)**; LD2–LD4 are RG13–RG15, BTN1/BTN2/BTN3 are RG6/RG7/RA0 (the pin names work as they
  are, e.g. `RG13`).
- Print and Input go over **UART1 (RF2/RF8)**, the board's USB-UART, at 115200 baud.
- **MQTT over Ethernet** (Settings → PIC32 → PIC32 MQTT over → Ethernet) is allowed for it: the board's PHY is a
  **LAN8720** (choose that one in Harmony's MAC driver).
- Upload uses the PIC32 upload command, e.g. a PICkit with pic32prog or ipecmd (Settings → PIC32 → Programmer).
- In the Board list, under Devices → PIC32 Chips, and on the command line as `--board chipkit-pro-mx7`.

## 32F429IDISCOVERY (STM32)

ST's STM32F429I-DISC1: an **STM32F429ZI**, 2 MB flash, 256 KB RAM, with an ST-LINK/V2-B.

- **STM32 C**: 168 MHz from the internal oscillator (the F407's clock setup, which the F429 runs without its
  over-drive), a linker script for 2048 KB of flash and the 192 KB of SRAM from 0x20000000 (the 64 KB CCM RAM is not
  used), Print and Input on **USART1 (PA9/PA10)**: the ST-LINK's virtual serial port, so the board's one USB cable
  carries both upload and output.
- `LED_BUILTIN` is **LD3, the green LED (PG13)**; LD4 is red on PG14, the user button B1 is PA0.
- **Arduino**: STMicroelectronics' core, `STMicroelectronics:stm32:Disco:pnum=DISCO_F429ZI`.
- Upload with OpenOCD through the ST-LINK (`target/stm32f4x.cfg`), as for the other STM32 boards.
- On the command line: `--board disco-f429zi`.

## Checks

- `check-pic32.sh` builds every example for the Pro MX7 too, with the WiFi module and with Ethernet (212 checks).
- `check-stm32.sh` builds every example for the F429 Discovery with clang and arm-none-eabi-gcc (vector table at
  0x08000000) and its Arduino sketches (96 STM32 C checks, with QEMU).
- Neither board has been tried on real hardware yet.
