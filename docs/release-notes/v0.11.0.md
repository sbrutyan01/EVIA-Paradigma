# EVIA Paradigma 0.11.0

**Native executables, and EVIA Paradigma Native.** The blocks now compile straight to machine code: no C, no compiler,
no assembler, no linker. An update package: 0.9.0 to 0.10.1 take it from **Settings → Packages and Updates…** and
start 0.11.0 the next time.

## A compiler from blocks to machine code

- `--native program.evia -o program` writes a **Linux x86-64 executable**: a static ELF file of about 33 KB that talks
  to the kernel with system calls only (no libc, no shared libraries), so it runs on any x86-64 Linux.
- It behaves as the interpreter does, exactly: the same output, the same error messages on stderr (`>> error: ...`),
  the same exit code, the 400-call limit on nested methods, Input with its prompt. Numbers are written as Java writes
  them (the shortest digits that read back: `0.30000000000000004`, `1.0E-5`, `4.9E-324`) and read as
  `Double.parseDouble` reads them, correctly rounded, with exact big-number arithmetic.
- Safe values (numbers and text with every check) and fast values (plain doubles), classes and objects, every flow
  block, **Delay** and **Millis**. The board, bus and phone blocks need their own languages.
- Inside: the blocks are lowered to a small internal language, every block a label and every wire a jump; the
  runtime is written in the same language (strings, buffered output, Input, big whole numbers for the number
  conversions); `NativeAsm` encodes x86-64 and `NativeElf` writes the file. Nothing outside EVIA Paradigma is used.

## EVIA Paradigma Native

A second application, built from the same code: the editor, blocks, classes, projects, Git and Run, without the
Language list and the code window.

- **Build executable** (F7) and **Run executable** (F6), with Input typed in a field under the output; the program goes
  to the project's `build/` folder, or next to the program file.
- **Values: Safe / Fast** in the toolbar; the palette has the program blocks and Delay and Millis.
- Installers of its own: `EVIA-Paradigma-Native-0.11.0-windows-x64.exe`, `-macos-arm64.dmg`, `-macos-x64.dmg`,
  `evia-paradigma-native_0.11.0_amd64.deb` (in `/opt/evia-paradigma-native`, command `evia-paradigma-native`) and
  `EVIA-Paradigma-Native-0.11.0-x86_64.AppImage`. It installs next to EVIA Paradigma and shares its settings and
  update packages; `.evia` files stay with EVIA Paradigma.
- On Windows and macOS it builds the same Linux executables (Windows and ARM executables are next).

## Checks

- `scripts/check-native.sh`: every example and test program, safe and fast, compiled and run against the
  interpreter (27 of 27), and 100,000 numbers read and written exactly as Java does. In CI on every push.
- The Native edition's installers are smoke-tested by building and running an executable.
