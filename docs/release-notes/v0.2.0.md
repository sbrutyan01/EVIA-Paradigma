# EVIA Paradigma 0.2.0

Classes with fields, constructors and several methods; class modules; a full menu bar with help;
"View C++ source" on any block; project folders with Git and GitHub.

## Classes

- **Class window** (Edit → New Class…, or double-click a class in the palette):
  - **Fields** tab: each field has an initial value expression (`balance` = `opening * 2`), in order.
  - One tab per **method**, each with its name, parameters and its own block program (Enter → Exit).
  - **+ Constructor** adds `init`, which runs once when an object is created, after the fields are initialized.
- **Named objects:** a call block now picks the method, the object and the arguments
  (double-click it or right-click → *Method, object and arguments…*). Blocks with the same object name share
  one object, e.g. `acc.deposit(10)` and later `acc.report()`.
- The palette lists every method: `Counter.add(n)`, `Counter.show()`, `Account.deposit(x)` …
- Ctrl+G still turns a selection into a class (with one method) without changing what the program does.

## Modules

- **File → Export Classes as Module…** moves classes into a `.eviam` file; **File → Import Module…** adds one.
- Programs refer to modules by relative path, and saving the program saves its modules too.
- New example `examples/classes.evia` with `examples/modules/counter.eviam`.
- Programs from 0.1.x still open (each custom block becomes a class with a method `run`).

## Menus and help

- **File**, **Edit**, **Run**, **Git** and **Help** menus with the usual shortcuts (Ctrl+N/O/S, F5, F7, Ctrl+K, F1 …).
- Asks before closing or replacing a program with unsaved changes.
- **Help → Guide** (F1): getting started, blocks, expressions, classes, modules, projects, Git, C++, shortcuts, Vim keys.
- Help → Examples, Online Documentation, Report an Issue, Check for Updates, About.

## View C++ source

Right-click any block → **View C++ source**: the generated C++ opens with exactly the lines produced by that block
highlighted. Works for a method or a whole class too.

## Projects and GitHub

- **File → New Project…** creates `MyProject/` with `MyProject.eviaproj`, `main.evia`, `modules/`, `build/`,
  `README.md`, `.gitignore`, a Git repository on branch `main` and a first commit.
- **Git** menu: Initialize, Commit… (Vim-key message editor), Push, Pull (fast-forward only), Connect to GitHub…,
  Open on GitHub, Status, History. It runs the git installed on your computer with the login it already has;
  EVIA Paradigma never stores passwords or tokens.
- In a project, Generate C++ also writes `build/<name>.cpp`; `evia --run MyProject` runs a project from the command line.
- Installers register `.eviaproj` files.

## Checks

- Examples: interpreter and compiled C++ (Clang and GCC, `-Werror`) give identical output, including the new classes example.
- New `scripts/check-app.sh` in CI: modules export/import/reload, View-C++ line mapping, project creation, and
  git init/commit/push/pull against a local bare repository.
