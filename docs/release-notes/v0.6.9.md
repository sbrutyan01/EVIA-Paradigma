# EVIA Paradigma 0.6.9

Python 3 joins the languages: a block program becomes one `.py` file that runs anywhere Python 3.8 or newer does.

## Language → Python 3

- **Generate code** with Language *Python 3* (or `--lang python` on the command line) writes one self-contained file:
  the program, its classes and a small runtime at the top. It needs nothing but Python itself.
- Classes become Python classes (`self.f_field`, methods `m_name(self, ...)` that return the index of the Exit they
  left through); program variables are module globals `v_name`; objects are created on first use, as in the
  interpreter.
- Print, Input, the number text (`0.30000000000000004`, `1.0E-4`) and every error message are the interpreter's, so a
  program prints the same in the editor, in C, in C++ and in Python. Errors end with `>> error: ...` and exit code 1.

| Flow | Python |
|---|---|
| Structured | nested `if`/`else` and `while` loops; *for* is a `while` with its step at the end, *do-while* a `while True` that tests at the end |
| Goto (and wiring that isn't block-structured) | a state machine: `while True:` with one branch per block, every wire written as `rt_s = "L7"` |

| Values | Python |
|---|---|
| Safe | `float` or `str`, with the interpreter's checks: undefined variables, division by zero, text that isn't a number, 400 nested calls |
| Fast | plain floats, text only in Print, no checks (dividing by zero gives `Infinity` or `NaN`, as in C) |

## Running it

- **Run** in the code window starts the program with Python; text typed into **Input** goes to it.
- **Settings → Python** holds the command. By default EVIA Paradigma finds it: `py` on Windows (the python.org
  installer's launcher), `python3` on Linux and macOS. **Detect** looks again, **Check** shows the version, and
  **Where?** opens python.org's download page.

## Tested

`scripts/check-targets.sh` now runs Python next to the C and C++ standards: every example and test program, both
flows and both value modes, must match the interpreter in output, errors and exit code. Python's number text was also
compared with Java's on 200,000 values, including the edge cases (subnormals, `1.0E7`, `-0`).
