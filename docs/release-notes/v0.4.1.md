and the fonts.

## Dark mode and the IntelliJ look

- **View > Theme:** *Same as system*, *Light (IntelliJ)* or *Dark (Darcula)*. The choice applies at once to every open
  window and is remembered. *Same as system* reads the setting of Windows, macOS or GNOME/KDE.
- The interface uses [FlatLaf](https://github.com/JFormDesigner/FlatLaf) 3.8: flat buttons, round scroll bars, the
  IntelliJ light theme and Darcula.
- The diagram canvas, wires, selection, the output panels and the code window follow the theme. The syntax colors of the
  code window are Darcula's in the dark theme. Blocks keep their colors in both themes.
- **Fonts:** Inter for the interface and JetBrains Mono for code, blocks and output, as in IntelliJ IDEA. Both are
  bundled (SIL Open Font License), so the app looks the same on every system. The interface font also has the Armenian
  letters (Noto Sans Armenian), because Java does not take missing letters from another font.

## Guide in Russian and Armenian

- **Help > Guide** has a language list above the topics: English, Русский, Հայերեն. The guide opens in the language of
  your system when it is one of these, and remembers your choice. All 11 topics are translated, with the same tables
  and examples. The menus and buttons of the program stay in English, so the guide names them as they appear.
- The guide follows the theme and the new fonts.

## Under the hood

- The jar contains FlatLaf, so `java -jar evia-paradigma-0.4.1.jar` is still all it takes (maven-shade-plugin).
  The installers' Java runtime also includes `java.logging`, which FlatLaf uses.
- Licenses of the bundled components: [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md).
- New checks: the three guides have the same topics, tables and code samples; the fonts have the Russian and Armenian
  letters; the themes have their own colors.
- New screenshots for the whole tutorial, plus the dark theme and the guide in Russian and Armenian.
