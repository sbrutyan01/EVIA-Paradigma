# EVIA Paradigma 0.3.1

Zoom block diagrams with the mouse wheel.

## Zoom

- Turn the **mouse wheel** over a diagram (the main program, or a method in a class window) to zoom in and out from
  25% to 300%. The point under the pointer stays in place, so you zoom into what you're looking at.
- Blocks, text and wires are drawn sharply at every size, and wires keep their shape.
- Editing works at any zoom: dragging blocks, drawing wires, rectangle selection, right-click menus and dropping
  blocks from the palette.
- Positions in saved files are in diagram units, so a program saved at 300% is identical to one saved at 100%.
- **Shift+wheel** scrolls sideways, **Ctrl+wheel** up and down.
- New **View** menu: Zoom In (Ctrl+=, number pad +), Zoom Out (Ctrl+-), Actual Size (Ctrl+0), Fit Diagram in
  Window (Ctrl+9).
- **`− 100% +`** zoom control at the bottom right of the main window.
- **Settings → Mouse wheel zooms block diagrams**: turn it off for the classic behavior, where the wheel scrolls and
  Ctrl+wheel zooms.

## Fixes (found by the Windows CI job after 0.3.0)

- Whole numbers beyond 32 bits are written as `10000000000.0` in generated code. On Windows `long` is 32-bit, so
  `10000000000` was a `long long` literal, which C++98 `-pedantic` rejects.
- The test scripts compare output ignoring `\r\n` line endings.

## Checks

- New `scripts/check-zoom.sh`, run in CI under Xvfb, drives the real main window with mouse-wheel, drag and drop
  events. It checks the zoom anchor (the point under the pointer moves at most 1 px), the 25%/300% limits, scrolling
  with Shift and Ctrl, that saved files don't change with the zoom, that a 100 px drag at 200% moves a block
  50 units, drop positions, Actual Size and Fit.
- All earlier checks: every language and mode against the interpreter (Clang, GCC, llvm-mingw), examples,
  application and Git.
