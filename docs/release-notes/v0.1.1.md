Bug-fix release: **compiling on Windows without Visual Studio**.

### Fixed
- On Windows, *Compile & Run* failed with `fatal error: 'cerrno' file not found` when Clang came from the official LLVM installer, which has no C++ standard library of its own.

### New
- **Install Clang…** (in Settings, and offered automatically when a compile fails for this reason) downloads the latest [llvm-mingw](https://github.com/mstorsjo/llvm-mingw/releases): Clang with its own C++ library (libc++) and Windows headers. It's installed into `%LOCALAPPDATA%\EVIA Paradigma\llvm-mingw`. No Visual Studio, no admin rights, no PATH changes.
- Programs are linked with `-static`, so the compiled `.exe` runs on any Windows PC.
- **Settings → Check** now test-compiles the C++ runtime, so a missing compiler or C++ library is reported before you press *Compile & Run*.
- CI compiles every example on Windows with llvm-mingw (no Visual Studio) and compares the output with the interpreter.

### Download
Every installer includes its own Java runtime, so Java doesn't need to be installed.

| System | File |
|---|---|
| Windows 10 / 11 (x64) | `EVIA-Paradigma-0.1.1-windows-x64.exe` |
| macOS, Apple Silicon | `EVIA-Paradigma-0.1.1-macos-arm64.dmg` |
| macOS, Intel | `EVIA-Paradigma-0.1.1-macos-x64.dmg` |
| Ubuntu 22.04+ / Debian 12+ | `evia-paradigma_0.1.1_amd64.deb`: install with `sudo apt install ./evia-paradigma_0.1.1_amd64.deb` |
| Any OS with Java 25 | `evia-paradigma-0.1.1.jar` |

The installers aren't code-signed yet. On Windows, click **More info → Run anyway** on the SmartScreen warning. On macOS, right-click the app and choose **Open** the first time.
