# EVIA Paradigma 0.10.1

**Android examples and the phone's sensors.** An update package: 0.9.0 to 0.10.0 take it from **Settings → Packages
and Updates…** and start 0.10.1 the next time.

## Phone Sensor block

A new block in the palette group **Phone** stores a reading of the phone in a variable, e.g. `ax = ACCEL_X`:

| Sensor | What it is |
|---|---|
| `ACCEL_X`, `ACCEL_Y`, `ACCEL_Z` | acceleration in m/s², gravity included (about 9.81 on Z when the phone lies flat), 0.01 resolution |
| `GYRO_X`, `GYRO_Y`, `GYRO_Z` | rotation in rad/s, 0.001 resolution |
| `LATITUDE`, `LONGITUDE` | the position in degrees, 6 decimals |
| `ALTITUDE`, `GPS_ACCURACY` | metres, 0.1 resolution |
| `GPS_FIX` | 1 once the position is known, 0 before |

- **Language Android** reads the real accelerometer, gyroscope and GPS (the network position until the GPS has a fix).
  An app that reads the position asks for the location permission when it starts; one that does not never asks.
- **Run** simulates a phone lying on a table in Yerevan that rocks gently, following the simulated clock, so a program
  can be tried on the computer first.
- Other languages say that the block needs Language Android instead of compiling something that cannot work.
- **Delay** and **Millis** now work in Java, Kotlin and Android too (on a phone, closing the app ends a Delay).

## Examples

**File → Open Example → Android Phones** (they also switch the language to Android):

- **Hello, world**: prints in three languages and asks for a name.
- **GPS viewer**: the position once a second: latitude, longitude, altitude and accuracy, or a note while there is no fix.
- **Motion tester**: the accelerometer and gyroscope twice a second, with *shake!* on a strong jolt and *face down* when
  the phone is turned over.
