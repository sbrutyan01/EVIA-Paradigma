# EVIA Paradigma 0.12.1

**The `evia` command in every installer.** 0.12.0 added the `evia` command (`evia gen`, `watch`, `check`, `run`,
`langs`, `boards` ...; see the [0.12.0 notes](v0.12.0.md)), but only the Windows installer had a launcher for it.

- **Linux (.deb):** `/usr/bin/evia`, next to `evia-paradigma` (left alone if another package already owns
  `/usr/bin/evia`). The AppImage takes the same commands: `./EVIA-Paradigma-0.12.1-x86_64.AppImage gen app.evia -l python`.
- **macOS:** `/Applications/EVIA Paradigma.app/Contents/MacOS/evia`; to type just `evia`:
  `sudo ln -s "/Applications/EVIA Paradigma.app/Contents/MacOS/evia" /usr/local/bin/evia`.
- **Windows:** `evia.exe` in the install folder, as before; it now takes the subcommands.
- **Any OS with Java 25:** `java -jar evia-paradigma-0.12.1.jar gen app.evia -l python`.

An update package: 0.9.0 to 0.12.0 take it from **Settings → Packages and Updates…** (the `evia` launcher itself
comes with the installer).
