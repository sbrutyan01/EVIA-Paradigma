First public release of **EVIA Paradigma**: visual block programming in Java Swing.

### Highlights
- **Block editor:** drag blocks from the palette, wire them together, and run with step highlighting
- **Custom blocks like classes:** definitions with parameters, `this.fields` and named exits; every placed block is an object with its own state; recursion; Ctrl+G groups a selection into a new custom block
- **C++20 generation:** one self-contained file with an embedded runtime whose output matches the built-in interpreter exactly
- **Clang 23** (latest stable LLVM) as the default compiler, with a version check in Settings
- **Vim everywhere:** built-in Vim keys in the C++ editor and block dialogs (`:w`, `:make`, `:s`, text objects, registers, `.`), plus *Edit in Vim…* for the real Vim/gVim
- **Command line:** `--run` and `--gen` for scripts and Makefiles
- EVIA logo as the application icon

### Download
Every installer includes its own Java runtime, so Java doesn't need to be installed.

| System | File |
|---|---|
| Windows 10 / 11 (x64) | `EVIA-Paradigma-0.1-windows-x64.exe` |
| macOS, Apple Silicon | `EVIA-Paradigma-0.1-macos-arm64.dmg` |
| macOS, Intel | `EVIA-Paradigma-0.1-macos-x64.dmg` |
| Ubuntu 22.04+ / Debian 12+ | `evia-paradigma_0.1_amd64.deb`: install with `sudo apt install ./evia-paradigma_0.1_amd64.deb` |
| Any OS with Java 25 | `evia-paradigma-0.1.jar` |

The installers aren't code-signed yet. On Windows, click **More info → Run anyway** on the SmartScreen warning. On macOS, right-click the app and choose **Open** the first time.

To compile generated programs, install LLVM/Clang 23.
