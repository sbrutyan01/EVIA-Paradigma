# EVIA Paradigma 0.9.1

A Terminal window for boards and other computers, and the PIC32 uploader as a package. This is the first
**update package**: an installed 0.9.0 takes it from **Settings → Packages and Updates…** (it also says so in the
status bar once a day) and starts 0.9.1 the next time, or at once with **Restart Now**. Nothing is uninstalled.

## Terminal

**Terminal** in the toolbar (also **Help → Terminal (UART, SSH)**) opens a real terminal emulator, JediTerm (the one in
the JetBrains IDEs), with one tab per session:

- **UART**: a board's serial port, chosen from a list (**Scan** finds the ones plugged in) or typed; the baud rate
  (115200 for Print and Input of EVIA programs); what the Enter key sends (CR, LF or CR LF); and **local echo** for the
  many boards that do not send back what you type. The port is the one Upload uses, so close the tab before uploading.
  On Linux the user needs to be in the `dialout` group, as for Upload.
- **SSH**: another computer (a Raspberry Pi, a board running Linux, a server), with a password or a key
  (`~/.ssh/id_ed25519` is offered if you have one; a key with a passphrase asks for it). A host seen for the first
  time shows its key fingerprint for you to accept, and is remembered in `~/.ssh/known_hosts`, like OpenSSH does.
  The terminal is xterm-256color and follows the size of the window, so colours, cursor keys and full-screen programs
  (`top`, `htop`, `vim`, `nano`) work.
- The colours follow the light or dark theme; the font is JetBrains Mono.

## pic32prog, a package

[pic32prog](https://github.com/sergev/pic32prog) uploads PIC32 programs through a PICkit2, a PICkit3 in its PICkit2
mode, the chipKIT and Microchip bootloaders or an FT2232 JTAG adapter. Its project publishes no builds newer than 2016,
so a workflow of this repository (`pic32prog.yml`) builds it from a pinned commit for Windows, macOS (Apple Silicon and
Intel) and Linux (x64 and ARM64), with libusb and hidapi linked in, and the package server serves it.

- **Settings → PIC32… → Get** installs it; the default upload command, `pic32prog {hex}`, then uses it by itself.
- XC32 still comes from Microchip (Settings → PIC32 → Get XC32): its licence does not allow passing it on.
