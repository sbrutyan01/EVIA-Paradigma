New flow-control blocks, with structured C++ generation.

### New
- **If / Else** (the former *If*, with `then` / `else` ports)
- **For** loop: `i = 1; i <= 10; i = i + 1` (init; condition; step, each part optional)
- **While** loop: condition checked before each pass
- **Do-While** loop: the body runs first, and the condition is checked after each pass
- Wire the end of a loop's body back into the loop block to close the loop. Loops nest, and an inner For starts over on each pass of the outer loop.
- **Structured C++:** *Generate C++* now writes real nested `if/else`, `for`, `while` and `do-while`. Free-form wiring, such as jumping out of the middle of a loop, still works: that part falls back to labels and `goto` with identical behaviour.
- New example `examples/loops.evia`. The built-in example now uses a While loop.

### Verified
Interpreter and generated C++ were compared on loops, nested loops, `continue`- and `break`-style wiring, jumps into a loop body, empty and self-wired loop bodies, unconnected outputs, multi-exit custom blocks inside loops and loops inside custom blocks. Output matched exactly with Clang and GCC (`-Wall -Wextra -Wpedantic -Werror`), and CI also checks Windows with llvm-mingw.

### Download
Every installer includes its own Java runtime, so Java doesn't need to be installed.

| System | File |
|---|---|
| Windows 10 / 11 (x64) | `EVIA-Paradigma-0.1.2-windows-x64.exe` |
| macOS, Apple Silicon | `EVIA-Paradigma-0.1.2-macos-arm64.dmg` |
| macOS, Intel | `EVIA-Paradigma-0.1.2-macos-x64.dmg` |
| Ubuntu 22.04+ / Debian 12+ | `evia-paradigma_0.1.2_amd64.deb`: install with `sudo apt install ./evia-paradigma_0.1.2_amd64.deb` |
| Any OS with Java 25 | `evia-paradigma-0.1.2.jar` |

On Windows, C++ is compiled with Clang from llvm-mingw (*Settings → Install Clang…*); no Visual Studio is needed.
The installers aren't code-signed yet. On Windows, click **More info → Run anyway** on the SmartScreen warning. On macOS, right-click the app and choose **Open** the first time.
