# EVIA Paradigma 0.4.0

Block programs for microcontrollers, and GCC next to Clang.

## Arduino and ESP32 boards

- **Board blocks** (a new group in the palette): Pin Mode, Digital Write, Digital Read, Analog Read,
  Analog Write (PWM), Delay and Millis. Pins can be numbers, expressions, `LED_BUILTIN` or `A0` … `A15`;
  `HIGH` and `LOW` work in any expression.
- **Language: Arduino** writes one sketch (`.ino`, `setup()` and `loop()`) for 12 boards:
  Arduino Uno, Nano, Mega 2560, Leonardo, Micro, Pro Mini (5 V, 16 MHz), ESP32, ESP32-S2, ESP32-S3, ESP32-C3,
  ESP32-C6 and ESP32-H2. Print and Input use the serial port at 115200 baud; on AVR boards text stays in flash.
- **Language: AVR C** writes bare-metal C for the ATmega328P (Uno, Nano, Pro Mini), ATmega2560 (Mega 2560) and
  ATmega32U4 (Leonardo, Micro). It needs only avr-gcc and avr-libc, no Arduino core: `pinMode`, `digitalWrite`,
  `digitalRead`, `analogRead`, `analogWrite`, `millis` and `delay` are implemented against the chip's registers
  (ports, timers 0–5, the ADC, a 115200-baud UART), with Arduino's pin numbers. A program includes only the parts it uses;
  blink is about 4 KB of flash and 20 bytes of RAM.
- **Board** list next to the language (and in Settings, with the serial port and the paths of arduino-cli, avr-gcc
  and avrdude). In the code window, **Build** compiles for the board and **Upload** sends the program to it.
- **Run simulates an Arduino Uno**:
  - pin changes appear in the output with their time;
  - time is virtual, so runs are repeatable;
  - a button on each input pin is pressed every other second;
  - analog pins read a slow wave.

  The command line sends the pin changes to stderr.
- **Examples**: File → Open Example → Arduino and ESP32 Boards: blink, button, fade (PWM), analog meter, and a `Led`
  class with a method that has two exits (`on` / `off`).

## Compilers

- **Settings → Compiler: Clang or GCC.** GCC uses `g++` for C++ and `gcc` for C; GCC 13 or newer compiles every
  language and mode.
- **Windows: Install GCC…** downloads the latest WinLibs MinGW-w64 GCC (UCRT), just as **Install Clang…** downloads
  llvm-mingw. No Visual Studio and no admin rights are needed, and programs are linked with `-static`.

## Fixes

- The code window and Settings no longer show the result of an older compiler check when a newer one finishes first.
- The code window toolbar has two rows, so Compile & Run (or Build / Upload) stays visible in narrow windows.

## Testing

- New CI job **boards** ([`scripts/check-boards.sh`](../../scripts/check-boards.sh)):
  - **Bare-metal AVR C:** every board example in both flows, built for all three chips with avr-gcc 14 and
    `-Wall -Wextra -Werror`.
  - **simavr:** each AVR build runs with the same button and analog signal as the simulated Uno. The UART output must
    match the interpreter, and the LED must switch as often on the right port bit.
  - **Arduino sketches:** built with arduino-cli for all 12 boards. The Uno and Mega 2560 builds also run in simavr.
- Windows CI also builds every language and mode with WinLibs GCC and checks the programs need no compiler DLLs.
