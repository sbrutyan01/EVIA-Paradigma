# EVIA Paradigma 0.9.3

The Linux build systems of 0.9.2 are now **packages of the EVIA server**, next to the toolchains. An update package:
an installed 0.9.0, 0.9.1 or 0.9.2 takes it from **Settings → Packages and Updates…** and starts 0.9.3 the next time
(or at once with **Restart Now**).

## The packages

| Package | Version | What is in it | Download |
|---|---|---|---|
| `buildroot` | 2026.02.3 (LTS) | the Buildroot release | 8 MB |
| `yocto` | 5.0.21 Scarthgap (LTS) | Poky (the release tarball) and meta-raspberrypi (`018d444` of scarthgap) | 18 MB |
| `openwrt` | 25.12.6 | the OpenWrt sources; on x86-64 also the Image Builders for the BeagleBone Black (`omap/generic`) and Raspberry Pi 5 (`bcm27xx/bcm2712`) | 92 MB (x86-64) |

They are in the package panel (group *Linux images*), for Linux on x64 and ARM64, and the Linux Images window has a
**Get Sources…** button for the chosen build system. The window says whether the sources are installed.
On the command line: `--install buildroot yocto openwrt`.

## build.sh

- `fetch` copies the sources from the installed package. Without it, it downloads the **same pinned files** and checks
  their SHA-256 (it no longer clones a branch, so a folder builds the same thing later). OpenWrt's Image Builder from
  the package is checked against its `sha256sums` before it is unpacked.
- Yocto is pinned to the **5.0.21** release (it followed the scarthgap branch before).
- `EVIA_PACKAGES=/some/folder ./build.sh fetch` points a workspace at packages installed elsewhere.
- Workspaces made by 0.9.2 keep their sources; saving them in 0.9.3 writes the new `build.sh`.

The packages carry the build systems only: a build still downloads the compilers, kernels and packages it builds from
each project's servers.

## Checks

`scripts/check-linux.sh` (55 checks, in CI) also builds workspaces against stand-in packages: the sources are taken
from them, a damaged Image Builder is refused, and the pins in the application and in `fetch-toolchains.sh` agree.
The three packages were built with `build-packages.sh`, installed with `--install` and used by `build.sh fetch`.
