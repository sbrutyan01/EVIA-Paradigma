# EVIA Paradigma 0.7.0

Settings move to the File menu and are split by device family, and the board examples are sorted the same way.

## File → Settings

Settings is now a submenu of **File** (on macOS also under the application menu, Cmd+,), with one entry per area.
Each opens the Settings window at its own tab:

| Entry | What is there |
|---|---|
| General… (Ctrl+,) | interface language, Vim keys, mouse wheel, external editor |
| C, C++ and Python… | Clang or GCC and the compile command; the Python command, Detect, Check |
| Arduino Boards… | the Arduino board (Uno, Nano, Mega 2560, Leonardo, Micro, Pro Mini), serial port with Scan, arduino-cli |
| ESP32 Boards… | the ESP32 board (ESP32, -S2, -S3, -C3, -C6, -H2), serial port, arduino-cli, the ESP32 core and Install |
| AVR C (bare metal)… | serial port, avr-gcc, avrdude |
| PIC32… | the PIC32 chip, serial port, xc32-gcc, the upload command, MQTT over WiFi module or Ethernet |
| FPGA Boards… | the FPGA board, the Artix-7 flow, Vivado and the open-source tools, Get FPGA tools |

- Arduino and ESP32 are separate pages, each with its own board list; the board chosen last is the one the
  Arduino language builds for, as in the toolbar.
- The PIC32 chip and the FPGA board can now be chosen in Settings too, not only in the toolbar.
- One serial port is shared by every board page, and Scan on any page fills the list on all of them.
- **Settings…** in the code window opens the page for the language being shown.
- Settings is no longer in the Edit menu.

## File → Open Example

The board examples are split into **Arduino Boards**, **ESP32 Boards** and **PIC32 Boards** (next to
**FPGA Boards**). Each lists only the examples its boards can build, and opening one also sets the language and a
board of that family: the MQTT examples are under ESP32 and PIC32, the Ethernet Starter Kit II example under
PIC32 with that board chosen.

## Also

- Long hints in Settings wrap inside the window instead of running past its edge.
- The guide (F1), the README and the tutorials give the new menu paths. The tutorial PDFs still show the old
  example menu name until they are rebuilt.
