# EVIA Paradigma 0.3.0

Pure C and every C++ standard from C++98 to C++20, chosen from drop-down lists, with two generation modes.

## Languages

Generate code now writes **C99, C11, C17, C++98, C++11, C++14, C++17 or C++20**.

- **C**: one `struct` per class with functions `Class_m_method(Class *self, ...)`. It has a small runtime with only
  the helpers the program uses, so it compiles cleanly with `-Wall -Wextra -Wpedantic -Werror`. C11/C17 mark the
  error function `_Noreturn`.
- **C++98**: classic value class, raw pointers deleted by their owner, non-copyable classes.
- **C++11 / C++14**: `std::unique_ptr` (`std::make_unique` in C++14), member initializers.
- **C++17 / C++20**: `std::variant` and `std::to_chars`, as before.

## Generation modes

- **Flow: Structured / Goto**. Structured writes if/else, for, while, do-while and switch, with labels only where the
  wiring needs them. Goto writes every block as a label and every wire as a jump.
- **Values: Safe / Fast**. Safe keeps numbers and text with all of the interpreter's checks. Fast uses plain
  `double` variables and fields with no runtime checks, and text only in Print. Programs that keep text in variables
  are refused with the block that does it.

## In the application

- **Language / Flow / Values** drop-down lists in the main toolbar and in the code window. Changing them regenerates
  the code (and keeps the highlighted lines of *View source code*). The same choices are in **Run → Code Language and Mode**.
- A project remembers its language. Generate code writes `build/<name>.c` or `.cpp`.
- Compile & Run uses the matching compiler for the language: `clang`/`gcc` for C with `-lm`, the right `-std=`, and
  llvm-mingw `clang.exe` on Windows (no Visual Studio).
- Right-click → **View source code** (was "View C++ source") works in every language.
- Command line: `--gen program.evia --lang c11 --flow goto --values fast -o program.c`.

## Fixes

- A For loop whose counter isn't used in its condition no longer produces an undeclared variable in C++.

## Checks

- New `scripts/check-targets.sh`: every program in `examples/` and the new `tests/programs/` (numbers and formatting,
  text, objects and recursion, unstructured wiring, and all eight runtime errors) in **all 32 combinations**. Each is
  compiled with `-Wall -Wextra -Wpedantic -Werror` and must match the interpreter's stdout, stderr and exit code.
  Locally with Clang 18 and GCC 13: 384 of 384 identical in each. In CI it runs with Clang 23 and GCC, and on Windows
  with llvm-mingw Clang (`-static`, no Visual Studio DLLs).
- `scripts/check-app.sh` also checks the source map in C and C++98/14 and the compile commands.

Fast values refuse programs that keep text in variables, as intended. On Windows the programs need no Visual Studio DLLs.

The first Windows run of the new check found two problems, fixed in `main` after the release (both only show with the
strict test flags `-Wpedantic -Werror`, so the published installers work):

- Whole numbers beyond 32 bits are now written as `10000000000.0`: on Windows `long` is 32-bit, so `10000000000` was a
  `long long` literal, which C++98 `-pedantic` rejects.
- The test scripts compare output ignoring `\r\n` line endings (Git Bash's `sed` drops `\r` from the expected text).
