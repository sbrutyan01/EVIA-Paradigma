# EVIA Paradigma 0.6.8

The board's serial port is chosen from a list in Settings, and the ESP32 core installs from Settings too.

## Settings → Serial port

A drop-down of the serial ports there are now, each with what is on it:

| System | Ports listed | Names from |
|---|---|---|
| Linux | `/dev/ttyACM*`, `/dev/ttyUSB*`, `/dev/ttyAMA*`, `/dev/rfcomm*` | `/dev/serial/by-id` |
| macOS | `/dev/cu.*` (USB ones first) | the device name (CP210x, CH340, usbmodem) |
| Windows | `COM*` from the registry | the device's name in Device Manager |

- **Scan** looks again, e.g. after plugging a board in. Settings also scans when it opens.
- A port can still be typed by hand. A saved port that is not connected now stays chosen, and the line under the
  list says so.
- Nothing new is bundled: the list comes from the system itself.

## Settings → ESP32 core

A separate field for the ESP32 board package address (by default
`https://espressif.github.io/arduino-esp32/package_esp32_index.json`) with **Install** beside it. Install runs

    arduino-cli core update-index --additional-urls <address>
    arduino-cli core install esp32:esp32 --additional-urls <address>

with the arduino-cli from the field above, and shows its output as it comes. It installs the ESP32 compilers,
esptool and libraries (a few hundred MB) once; running it again updates them. When a sketch build fails because the
core is missing, the message now points to this button.

The new labels are translated into Russian and Armenian.
