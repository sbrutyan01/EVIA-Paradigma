# EVIA Paradigma 0.8.0

The installers bring the board toolchains with them, XC32 installs from inside the application, and two new menus,
**Settings** and **Devices**, sit between Git and Help.

## Toolchains inside the installers

The Windows, macOS and Linux installers (.exe, .dmg, .deb, AppImage) now carry, in a folder `toolchains/` inside
the application (`/opt/evia-paradigma/lib/toolchains` on Linux), everything bare-metal AVR C and the FPGA flows need. Nothing to download or set up: Build and
Upload use them by themselves.

| Toolchain | Linux x64 | Windows x64 | macOS (Apple Silicon and Intel) |
|---|---|---|---|
| avr-gcc + avr-libc | 16.1.0 | 16.1.0 | 7.3.0 (Arduino's build; under Rosetta on Apple Silicon) |
| avrdude | 8.0 | 8.0 | 8.0 (under Rosetta on Apple Silicon) |
| OSS CAD Suite (yosys, nextpnr, gmpack, openFPGALoader ...) | 2026-11-09 | 2026-11-09 | 2026-11-09 (native) |

- They are defaults: a path set in **Settings** still wins, and a field left at the bundled tool follows it
  through updates.
- `evia-paradigma --version` (or `evia --version` on Windows) says which tools this copy uses.
- Every file is pinned by version and SHA-256 in `packaging/fetch-toolchains.sh`; each folder has a `SOURCES.txt`
  with its licence and where its source is. See THIRD_PARTY_NOTICES.md.
- The installers are much bigger: about 0.8–1 GB to download and 3 GB installed. The jar on its own stays small
  and has no toolchains.

## XC32 from Microchip, in one step

Microchip's licence does not allow passing XC32 on, so it is not in the installers. Instead,
**Settings → PIC32… → Get XC32…**:

1. downloads Microchip's free XC32 4.35 installer from microchip.com (about 450 MB),
2. checks it is exactly Microchip's published file (size and SHA-256),
3. asks you to accept Microchip's licence agreement (with a link to read it),
4. runs Microchip's own installer in Free mode; it needs administrator rights, which your system asks for
   (a password prompt on Linux and macOS, UAC on Windows).

XC32 is then in Microchip's usual folder (`/opt/microchip/xc32`, `C:\Program Files\Microchip\xc32`,
`/Applications/microchip/xc32`), and EVIA Paradigma finds it there by itself, also when it was installed earlier
by hand.

## Settings and Devices menus

- **Settings** (between Git and Help) has the seven pages: General (Ctrl+,), C, C++ and Python, Arduino Boards,
  ESP32 Boards, AVR C (bare metal), PIC32, FPGA Boards. File → Settings is gone.
- **Devices** lists every device family with its boards: This Computer (C, C++, Python), Arduino Boards, ESP32
  Boards, AVR C (bare metal), PIC32 Chips, FPGA Boards. Choosing one sets the language and the board in one step,
  the current one is marked, and each family ends with its Settings page.
