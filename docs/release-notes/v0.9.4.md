# EVIA Paradigma 0.9.4

PIC32 upload with **Microchip's ipecmd** (MPLAB IPE), for the boards pic32prog cannot program: the
**PIC32MX Ethernet Starter Kit II** (its on-board programmer), the PICkit 4 and 5, the ICD 4 and 5 and the Snap.
An update package: 0.9.0 to 0.9.3 take it from **Settings → Packages and Updates…**.

## Settings → PIC32

- **Programmer** sets the upload command: pic32prog (PICkit2, PICkit3 in PICkit2 mode, bootloaders), or ipecmd for
  the starter kit's on-board programmer (`ipecmd -TPPKOB -P{chip} -M -F{hex} -OL`), PICkit 3/4/5, ICD 4/5 or Snap.
  `{chip}` is the chip chosen above, e.g. `32MX795F512L` for the Ethernet Starter Kit II; `-OL` lets the program run
  after programming.
- **Get MPLAB IPE…** installs IPE from Microchip's MPLAB X **v6.20** installer. IPE is Microchip's software: its
  licence does not let EVIA Paradigma pass it on, and Microchip's site lets the installer be downloaded only in a
  browser. So the button opens Microchip's page, you choose the downloaded installer, and EVIA Paradigma checks it (on
  Linux: size and SHA-256 of Microchip's published v6.20 file) and runs it for **IPE only**, with the 32-bit devices
  and nothing sent to Microchip. Your system asks for an administrator password.
- An upload command that starts with plain `ipecmd` runs the newest IPE in Microchip's usual place
  (`/opt/microchip/mplabx/v*/`, `C:\Program Files\Microchip\MPLABX\v*\`, `/Applications/microchip/mplabx/v*/`), so it
  follows MPLAB X updates.

## Also

- On Linux without a password dialog, the same install in a terminal:
  `sudo sh MPLABX-v6.20-linux-installer.sh -- --mode unattended --ide 0 --ipe 1 --8bitmcu 0 --16bitmcu 0 --32bitmcu 1 --othermcu 0 --collectInfo 0 --collectMyMicrochipInfo 0`
- `scripts/check-ipe.sh` (in CI): finding ipecmd, the presets and `{chip}`, the accepted installers and options, and
  (with `MPLABX_INSTALLER=`) the SHA-256 check.
- Guide and interface in Russian and Armenian.
- Not tested yet on a real Ethernet Starter Kit II: if ipecmd does not take `PKOB` for it, the upload command can be
  edited in Settings.
