EVIA Paradigma. ուղեցույց

EVIA Paradigma-ն տեսողական ծրագրավորում է. բլոկները գունապնակից քաշեք կտավի վրա, միացրեք դրանք կապերով և սեղմեք Run։ Նույն ծրագիրը կարելի է վերածել C (C99, C11, C17) կամ C++ (C++98-ից մինչև C++20) կոդի և կառուցել Clang-ով կամ GCC-ով, ինչպես նաև Arduino և ESP32 տախտակների կոդի։ Ծրագրի ինտերֆեյսն անգլերեն է, ուստի ընտրացանկերի և կոճակների անունները բերված են այնպես, ինչպես երևում են էկրանին։

  1. Կտավի վրա քաշեք Start-ը, մի քանի բլոկ և End-ը։
  2. Բլոկի ներքևի փոքր շրջանից (նրա ելքի պորտից) քաշեք դեպի մեկ այլ բլոկ՝ դրանք միացնելու համար։
  3. Բլոկի վրա կրկնակի սեղմումը բացում է նրա կոդը խմբագրելու համար։
  4. Մկնիկի անիվը սխեմայի վրա մոտեցնում և հեռացնում է այն ցուցիչի ուղղությամբ։
  5. Սեղմեք Run (F5)։ Ելքը երևում է ներքևի վահանակում. կատարվող բլոկը լուսավորվում է։
  6. Գործիքագոտում ընտրեք Language և սեղմեք Generate code (F7)՝ ծրագիրը տեսնելու, պահելու, կառուցելու և գործարկելու համար։

Տեսք և լեզու։ View > Theme-ը ընտրում է IntelliJ-ի բաց թեման, Darcula մուգ թեման կամ ձեր համակարգի կարգավորումը. թեման փոխվում է անմիջապես և հիշվում է։ Բաժինների ցանկի վերևում կարելի է ընտրել այս ուղեցույցի լեզուն՝ անգլերեն, ռուսերեն կամ հայերեն։

Արտահայտություններ

Արժեքները թվեր են կամ տեքստ։ Օպերատորները՝ ցածրագույն առաջնահերթությունից դեպի բարձրագույն.

  • ||   &&
  • == != < <= > >= (տեքստերը համեմատվում են այբբենական կարգով)
  • + - (+-ը միացնում է տեքստը, եթե որևէ կողմը տեքստ է)
  • * / %
  • ունար - և !, փակագծեր

Տեքստը գրվում է կրկնակի չակերտներով. թույլատրվում են \", \\, \n escape-հաջորդականությունները։ Պայմանը ճշմարիտ է, եթե դա ոչ զրոյական թիվ է կամ ոչ դատարկ տեքստ։

Դասեր և օբյեկտներ

Դասը միավորում է դաշտերը (տվյալներ, որոնք պահում է յուրաքանչյուր օբյեկտ) և մեթոդները (բլոկային ծրագրեր, որոնք աշխատում են այդ տվյալների հետ)։ Ստեղծեք այն Edit > New Class-ով, գունապնակի + New class-ով կամ նշեք բլոկները և սեղմեք Ctrl+G՝ դրանք դաս դարձնելու համար։

  • Fields ներդիրը. յուրաքանչյուր դաշտի անունը և սկզբնական արժեքը։ Սկզբնական արժեքները արտահայտություններ են և կարող են օգտագործել ծրագրի փոփոխականները և նախորդ դաշտերը։ Մեթոդների ներսում դաշտը գրվում է this.անուն։
  • Մեկ ներդիր յուրաքանչյուր մեթոդի համար. նրա անունը, պարամետրերը և մարմինը։ Մարմինը սկսվում է Enter-ով և ավարտվում Exit-ով։ Յուրաքանչյուր առանձին Exit անուն դառնում է կանչող բլոկի ելքային պորտ, օրինակ՝ yes / no։ Պարամետրերը գալիս են որպես դաշտեր. n պարամետրը կարդացվում է որպես this.n։
  • Կոնստրուկտոր. init անունով մեթոդ (կոճակ՝ + Constructor)։ Օբյեկտ ստեղծելիս նրա դաշտերը նախ ստանում են սկզբնական արժեքները, ապա մեկ անգամ կատարվում է init-ը։

Մեթոդը կանչելու համար այն գունապնակի Classes բաժնից քաշեք կտավի վրա։ Բլոկի վրա աջ կամ կրկնակի սեղմումով ընտրվում են մեթոդը, օբյեկտը և արգումենտները։ Նույն օբյեկտի անունով բլոկները աշխատում են մեկ օբյեկտի հետ (և նրա դաշտերի). առանց օբյեկտի անվան բլոկն ունի իր սեփական օբյեկտը։ Օբյեկտները ստեղծվում են առաջին օգտագործման ժամանակ։

Մոդուլներ

Մոդուլը (*.eviam) դասերի ֆայլ է, որը կարող են օգտագործել մի քանի ծրագրեր։

  • File > Export Classes as Module-ը դասերը տեղափոխում է մոդուլի ֆայլ։ Ծրագիրն այնուհետև հղվում է մոդուլին, և ծրագիրը պահելիս պահվում է նաև մոդուլը։
  • File > Import Module-ը մոդուլի դասերը ավելացնում է բաց ծրագրին։
  • Դասի պատուհանը ցույց է տալիս, թե որտեղ է պահվում դասը։

Նախագծեր

File > New Project-ը ստեղծում է թղթապանակ՝ ծրագրին անհրաժեշտ ամեն ինչով.

MyProject/
  MyProject.eviaproj   նախագծի կարգավորումներ
  main.evia            գլխավոր ծրագիրը
  modules/             դասերի մոդուլներ
  build/               գեներացված կոդ (չի մտնում commit-ների մեջ)
  README.md
  .gitignore

Նախագիծը նորից բացեք File > Open Project-ով (ընտրեք թղթապանակը կամ .eviaproj ֆայլը)։ Նախագծում մոդուլները ներմուծվում են modules/-ից և արտահանվում են այնտեղ, իսկ Generate code-ը լրացուցիչ գրում է build/<անուն>.c կամ .cpp։ Նախագիծը հիշում է իր լեզուն։

Git և GitHub

Git ընտրացանկը գործարկում է ձեր համակարգչում տեղադրված git-ը և օգտագործում է արդեն կարգավորված մուտքը (Git Credential Manager, SSH բանալի կամ gh auth login)։ EVIA Paradigma-ն երբեք չի խնդրում և չի պահում գաղտնաբառեր կամ թոքեններ։

  • Initialize Repository. git init main ճյուղում (նոր նախագծերը դա անում են ինքնուրույն, եթե git-ը տեղադրված է)։
  • Commit (Ctrl+K). պահում է ծրագիրը և commit է անում բոլոր փոփոխությունները. հաղորդագրության խմբագրիչում աշխատում են Vim ստեղները։
  • Connect to GitHub. մուտքագրեք սեփականատեր/պահոց կամ կլոնավորման URL։ Create repository on GitHub-ը բացում է github.com-ը զննարկչում՝ անունն արդեն լրացված. ստեղծեք դատարկ պահոց և սեղմեք OK։
  • Push / Pull. commit-ները ուղարկել GitHub / ստանալ նորերը (միայն fast-forward, այնպես որ ոչինչ չի միաձուլվում ձեր գիտությունից թաքուն)։
  • History-ն ցույց է տալիս վերջին commit-ները. Open on GitHub-ը բացում է պահոցի էջը։

Տեղադրեք git-ը git-scm.com-ից, եթե ընտրացանկը ասում է, որ այն բացակայում է։

Գեներացված կոդ. C և C++

Generate code (F7)-ը ամբողջ ծրագիրը վերածում է մեկ սկզբնական ֆայլի։ Գործիքագոտու երեք բացվող ցանկերը (և կոդի պատուհանում) որոշում են արդյունքը. նույն ընտրությունները կան Run > Code Language and Mode-ում։ Կոդի պատուհանում դրանք փոխելիս կոդը նորից է գեներացվում։

ՑանկՏարբերակներԻնչն է փոխվում
LanguageC99, C11, C17
C++98, C++11, C++14, C++17, C++20		 C. յուրաքանչյուր դասի համար struct և Class_m_method(self, ...) ֆունկցիաներ, փոքր runtime՝ միայն այն օգնականներով, որոնք օգտագործում է ծրագիրը։ C++. յուրաքանչյուր դասի համար անդամ-ֆունկցիաներով struct. C++98-ը օգտագործում է սովորական ցուցիչներ, C++11/14-ը՝ std::unique_ptr, C++17/20-ը՝ std::variant և std::to_chars։
FlowStructured
Goto		 Structured. if/else, for, while, do/while և switch (պիտակներ՝ միայն այնտեղ, որտեղ կապերը չեն տեղավորվում բլոկային կառուցվածքի մեջ)։ Goto. յուրաքանչյուր բլոկ պիտակ է, իսկ յուրաքանչյուր կապ՝ անցում, ամենամոտը սխեմային։
ValuesSafe
Fast		 Safe. թվեր և տեքստ՝ ինտերպրետատորի բոլոր ստուգումներով (չսահմանված փոփոխականներ, բաժանում զրոյի, թիվ չհանդիսացող տեքստ, անվերջ ռեկուրսիա)։ Fast. պարզ double փոփոխականներ և դաշտեր, տեքստ՝ միայն Print-ում, առանց կատարման ժամանակի ստուգումների։ Այն ծրագիրը, որը տեքստ է պահում փոփոխականում, չի կարող օգտագործել Fast արժեքներ. Generate code-ը կասի, թե որ բլոկն է խանգարում։

Յուրաքանչյուր համակցություն ստուգված է. ելքը համընկնում է ինտերպրետատորի ելքի հետ (Fast արժեքների դեպքում՝ առանց սխալների աշխատող ծրագրերի համար)։ Բլոկի, մեթոդի կամ դասի վրա աջ սեղմում → View source code՝ տեսնելու այն կոդը, որ դարձել է, լուսավորված, ձեր ընտրած լեզվով։

Կոդի պատուհանը կարող է պահել ֆայլը, կառուցել այն և գործարկել։ C-ի համար օգտագործվում է համապատասխան C կոմպիլյատորը (clang, gcc), ճիշտ -std= և -lm։ Կոմպիլյատորն ընտրվում է Settings-ում. Clang (clang++ / clang) կամ GCC (g++ / gcc, տարբերակ 13 կամ ավելի նոր)։ Windows-ում EVIA Paradigma-ն կարող է դրանցից ցանկացածը տեղադրել ինքնուրույն. llvm-mingw (Clang) կամ WinLibs (GCC, MinGW-w64)։ Visual Studio-ն պետք չէ։

Arduino և ESP32 տախտակներ

Եվս երկու լեզու կոդ են ստեղծում միկրոկոնտրոլերների համար։ Երկուսն էլ օգտագործում են արագ արժեքներ (թվեր. տեքստ՝ միայն Print-ում), իսկ Print-ը և Input-ը աշխատում են սերիական պորտով՝ 115200 բոդ արագությամբ։

ԼեզուՏախտակներԻնչով է կառուցվում
ArduinoArduino Uno, Nano, Mega 2560, Leonardo, Micro, Pro Mini;
ESP32, ESP32-S2, -S3, -C3, -C6, -H2		 Մեկ սքեթչ (.ino)՝ setup() և loop()-ով. arduino-cli՝ arduino:avr և esp32:esp32 միջուկներով։
AVR CArduino-ի վեց AVR տախտակները (ATmega328P, ATmega2560, ATmega32U4) Bare-metal C՝ առանց Arduino միջուկի։ Պինները, թայմերները, PWM-ը, ADC-ն և UART-ը կառավարվում են չիպի ռեգիստրներով։ Կառուցում են avr-gcc-ն և avr-libc-ը, բեռնում է avrdude-ը։

Տախտակն ընտրվում է լեզվի կողքի Board ցանկում (նաև Settings-ում)։ Կոդի պատուհանի Build-ը ծրագիրը կառուցում է դրա համար. Upload-ը կառուցում է և ուղարկում ծրագիրը տախտակին՝ Settings-ում նշված սերիական պորտով։

Պինները կարող են լինել թվեր, արտահայտություններ կամ տախտակի LED_BUILTIN, A0 ... A15 անունները. HIGH և LOW աշխատում են ցանկացած արտահայտության մեջ։ Այս անունները չի կարելի օգտագործել որպես փոփոխականներ։

Run-ը նմանակում է Arduino Uno. պինների փոփոխությունները ելքում երևում են board [500 ms] pin 13 HIGH տեսքով, ժամանակը առաջ է գնում միայն Delay-ում (գլխավոր պատուհանը նաև իրականում սպասում է, եթե արագության սահողը լրիվ արագության վրա չէ), յուրաքանչյուր մուտքային պինի կոճակը սեղմվում է ամեն 2 վայրկյանի երկրորդ կեսին, իսկ անալոգային պինները կարդում են դանդաղ 0..1023..0 ալիք։ Ծրագիրը կատարվում է մեկ անգամ, կարծես setup()-ից. դրանից հետո պինները պահում են իրենց վիճակը։ File > Open Example > Arduino and ESP32 Boards-ում կան օրինակներ՝ blink, button, fade, analog meter և Led դաս։

Համակարգչի լեզուները (C, C++) չեն կարող օգտագործել Board բլոկները. Generate code-ը կասի, թե որ բլոկը փոխել։

Vim ստեղներ

Կոդի դաշտերը, կոդի պատուհանը և commit-ի հաղորդագրության խմբագրիչը աշխատում են Vim ստեղներով (անջատվում են Settings-ում)։ Տեքստը բացվում է ներդրման ռեժիմում. Esc-ը անցնում է նորմալ ռեժիմի։

  • Խմբագրում. i a I A o O, x, dd, cw, yy, p, u, Ctrl+R, .
  • Նշում. v, V. որոնում. /տեքստ, n N, *
  • Հրամաններ. :w ընդունել/պահել, :q փակել, :wq, :s/a/b/g, :make կառուցել և գործարկել (կոդի պատուհան), :vim բացել իրական Vim-ում
