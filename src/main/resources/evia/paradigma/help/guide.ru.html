Руководство EVIA Paradigma

EVIA Paradigma — визуальное программирование: перетащите блоки из палитры на холст, соедините их связями и нажмите Run. Ту же программу можно превратить в код на C (C99, C11, C17) или C++ (от C++98 до C++20) и собрать с помощью Clang или GCC, а также в код для плат Arduino и ESP32. Интерфейс программы на английском, поэтому названия меню и кнопок даны так, как они выглядят на экране.

  1. Перетащите на холст Start, несколько блоков и End.
  2. Потяните от маленького круга внизу блока (его выходного порта) к другому блоку, чтобы соединить их.
  3. Двойной щелчок по блоку открывает его код для редактирования.
  4. Колесо мыши над схемой приближает и отдаляет её к указателю.
  5. Нажмите Run (F5). Вывод появится в панели внизу; выполняемый блок подсвечивается.
  6. Выберите Language на панели инструментов и нажмите Generate code (F7), чтобы увидеть, сохранить, скомпилировать и запустить программу.

Вид и язык. View > Theme выбирает светлую тему IntelliJ, тёмную тему Darcula или настройку вашей системы; тема меняется сразу и запоминается. Над списком разделов можно выбрать язык этого руководства: английский, русский или армянский.

Выражения

Значения — это числа или текст. Операторы, от низшего приоритета к высшему:

  • ||   &&
  • == != < <= > >= (тексты сравниваются по алфавиту)
  • + - (+ склеивает текст, если хотя бы одна сторона — текст)
  • * / %
  • унарные - и !, скобки

Текст пишется в двойных кавычках; допустимы escape-последовательности \", \\, \n. Условие истинно, если это ненулевое число или непустой текст.

Классы и объекты

Класс объединяет поля (данные, которые хранит каждый объект) и методы (блок-программы, работающие с этими данными). Создать класс можно через Edit > New Class, кнопкой + New class в палитре или выделив блоки и нажав Ctrl+G, чтобы превратить их в класс.

  • Вкладка Fields: имя и начальное значение каждого поля. Начальные значения — выражения; в них можно использовать переменные программы и предыдущие поля. Внутри методов поле записывается как this.имя.
  • По одной вкладке на каждый метод: его имя, параметры и тело. Тело начинается с блока Enter и заканчивается блоком Exit. Каждое отдельное имя Exit становится выходным портом вызывающего блока, например yes / no. Параметры поступают как поля: параметр n читается как this.n.
  • Конструктор: метод с именем init (кнопка + Constructor). При создании объекта его поля сначала получают начальные значения, затем один раз выполняется init.

Перетащите метод из раздела Classes палитры на холст, чтобы вызвать его. Правый щелчок по блоку или двойной щелчок позволяют выбрать метод, объект и аргументы. Блоки с одинаковым именем объекта работают с одним объектом (и его полями); у блока без имени объекта объект свой собственный. Объекты создаются при первом использовании.

Модули

Модуль (*.eviam) — это файл с классами, которые могут использовать несколько программ.

  • File > Export Classes as Module переносит классы в файл модуля. Программа начинает ссылаться на модуль, и при сохранении программы сохраняется и модуль.
  • File > Import Module добавляет классы модуля в открытую программу.
  • В окне класса показано, где он хранится.

Проекты

File > New Project создаёт папку со всем, что нужно программе:

MyProject/
  MyProject.eviaproj   настройки проекта
  main.evia            главная программа
  modules/             модули классов
  build/               сгенерированный код (не попадает в коммиты)
  README.md
  .gitignore

Откройте проект снова через File > Open Project (выберите папку или файл .eviaproj). В проекте модули импортируются из modules/ и экспортируются в неё, а Generate code дополнительно записывает build/<имя>.c или .cpp. Проект запоминает свой язык.

Git и GitHub

Меню Git запускает git, установленный на вашем компьютере, и использует уже настроенный вход (Git Credential Manager, SSH-ключ или gh auth login). EVIA Paradigma никогда не запрашивает и не хранит пароли или токены.

  • Initialize Repository: git init в ветке main (новые проекты делают это сами, если git установлен).
  • Commit (Ctrl+K): сохраняет программу и делает коммит всех изменений; в редакторе сообщения работают клавиши Vim.
  • Connect to GitHub: введите владелец/репозиторий или URL для клонирования. Create repository on GitHub открывает github.com в браузере с уже заполненным именем; создайте пустой репозиторий и нажмите OK.
  • Push / Pull: отправить коммиты на GitHub / получить новые (только fast-forward, поэтому ничего не сливается без вашего ведома).
  • History показывает последние коммиты; Open on GitHub открывает страницу репозитория.

Установите git с git-scm.com, если в меню написано, что его нет.

Сгенерированный код: C и C++

Generate code (F7) превращает всю программу в один исходный файл. Три выпадающих списка на панели инструментов (и в окне кода) определяют результат; те же варианты есть в Run > Code Language and Mode. Если изменить их в окне кода, код генерируется заново.

СписокВариантыЧто меняется
LanguageC99, C11, C17
C++98, C++11, C++14, C++17, C++20		 C: struct для каждого класса и функции Class_m_method(self, ...), небольшая библиотека времени выполнения только с теми помощниками, которые нужны программе. C++: struct для каждого класса с функциями-членами; C++98 использует обычные указатели, C++11/14 — std::unique_ptr, C++17/20 — std::variant и std::to_chars.
FlowStructured
Goto		 Structured: if/else, for, while, do/while и switch (метки только там, где связи не укладываются в блочную структуру). Goto: каждый блок — метка, а каждая связь — переход; ближе всего к схеме.
ValuesSafe
Fast		 Safe: числа и текст со всеми проверками интерпретатора (неопределённые переменные, деление на ноль, текст, который не является числом, бесконечная рекурсия). Fast: простые переменные и поля double, текст только в Print, без проверок во время выполнения. Программа, которая хранит текст в переменной, не может использовать значения Fast; Generate code укажет, какой блок мешает.

Каждое сочетание проверено: вывод совпадает с выводом интерпретатора (для значений Fast — у программ, которые выполняются без ошибок). Правый щелчок по блоку, методу или классу → View source code показывает код, в который он превратился, с подсветкой, на выбранном вами языке.

Окно кода умеет сохранять файл, компилировать его и запускать. Для C используется подходящий компилятор C (clang, gcc), нужные -std= и -lm. Компилятор выбирается в Settings: Clang (clang++ / clang) или GCC (g++ / gcc, версия 13 или новее). В Windows EVIA Paradigma может установить любой из них сам: llvm-mingw (Clang) или WinLibs (GCC, MinGW-w64). Visual Studio не нужна.

Ещё три языка создают код для микроконтроллеров. Оба используют быстрые значения (числа; текст только в Print), а Print и Input работают через последовательный порт на скорости 115200 бод.

MQTT. Имя сети, пароль, брокер и темы — это фиксированные тексты: они попадают в программу при сборке. PIC32 C управляет модулем ESP8266 или ESP32 с прошивкой AT через UART2 (RB5/RB1 на 28-выводных чипах, RF4/RF5 на остальных), поэтому Print остаётся на UART1. Arduino на плате ESP32 использует собственный WiFi платы. Запуск отвечает из брокера на вашем компьютере: публикация в тему, на которую вы подписаны, возвращает сообщение. Плата AVR отказывается от блоков MQTT (один последовательный порт, его занимает Print), FPGA тоже. Сообщение — это число, записанное так же, как его печатает Print; поскольку -1 означает ещё и «ничего не пришло», MQTT Has Message отличает настоящую -1. MQTT через порт Ethernet чипов MX695/795 пока не поддерживается.

Пины могут быть числами, выражениями или именами платы LED_BUILTIN, A0 ... A15; HIGH и LOW работают в любом выражении. Эти имена нельзя использовать как переменные.

Блоки шин работают в Run и во всех трёх языках для плат. Перед использованием шину нужно открыть; адреса 7-битные, числа десятичные (80 — это 0x50). На PIC32 пины фиксированы для семейства микросхем и перечислены в начале созданного кода (встроенные UART1, SPI и I2C1). Run имитирует шины: передатчик UART соединён с его приёмником, поэтому байты из UART Write возвращаются через UART Read (и также появляются в выводе как текст), вход SPI соединён с его выходом, а по адресу 80 отвечает одно устройство I2C с 256 регистрами.

Run имитирует Arduino Uno: изменения пинов появляются в выводе в виде board [500 ms] pin 13 HIGH, время идёт вперёд только в Delay (главное окно при этом реально ждёт, если ползунок скорости не стоит на полной скорости), кнопка на каждом входном пине нажимается во второй половине каждых 2 секунд, а аналоговые пины читают медленную волну 0..1023..0. Программа выполняется один раз, как будто из setup(); после этого пины сохраняют своё состояние. В File > Open Example > Arduino and ESP32 Boards есть примеры: blink, button, fade, analog meter, класс Led и примеры UART, SPI и I2C.

Языки для компьютера (C, C++) не могут использовать блоки Board; Generate code укажет, какой блок нужно заменить.

FPGA: Artix-7 и GateMate

Ещё три языка, SystemVerilog, Verilog-2001 и VHDL (VHDL-2008), превращают ту же схему в аппаратуру. Каждый блок становится одним состоянием конечного автомата и занимает один такт. Переменные — знаковые 32-битные регистры.

Digilent Arty A7-35 / A7-100Artix-7100 МГц4 светодиода, 4 переключателя, 4 кнопки, JA-JD, USB-UART

Выводы фиксируются при сборке, поэтому вывод должен быть числом или именем: LED0, SW3, BTNC, BTN0, JA1. Если на плате нет такого вывода, будет ошибка со списком имеющихся. Вывод нельзя одновременно читать и записывать.

Целые числа. Арифметика переполняется по модулю 32 бит; / и % округляют к нулю, деление на 0 даёт 0. Запуск использует числа double, поэтому 5 / 2 в Запуске равно 2.5, а на FPGA — 2. Пока не поддерживаются: классы, Input, Analog Read, SPI, I2C и текст в переменных (в Print текст работает).

Сборка и загрузка. Artix-7: Vivado в пакетном режиме или открытая цепочка (yosys, nextpnr-xilinx, Project X-Ray), выбирается в Настройках. GateMate: yosys, nextpnr-himbaechel, gmpack. Загрузка — Vivado или openFPGALoader. Ограничения выводов лежат в первом комментарии файла, а -o в командной строке также записывает файл .xdc или .ccf.

Проверено: моделирование в сравнении с Запуском и синтез открытыми средствами. Не проверено: Vivado, openXC7 и реальные платы.

Примеры: Файл > Открыть пример > FPGA Boards.

Клавиши Vim

Поля кода, окно кода и редактор сообщения коммита работают с клавишами Vim (отключаются в Settings). Текст открывается в режиме вставки; Esc переключает в нормальный режим.

  • Перемещение: h j k l, w b e, 0 ^ $, gg G, %, f t
  • Правка: i a I A o O, x, dd, cw, yy, p, u, Ctrl+R, .
  • Выделение: v, V; поиск: /текст, n N, *
  • Команды: :w принять/сохранить, :q закрыть, :wq, :s/a/b/g, :make скомпилировать и запустить (окно кода), :vim открыть в настоящем Vim
