EVIA Paradigma — визуальное программирование для тех, кто хочет видеть, что получает машина. Схема и есть программа, а язык — это настройка. Соединяйте блоки на холсте, запускайте их, а затем выбирайте, во что они превратятся: от C99 до C++20 со сборкой Clang или GCC, программа на Python 3, Java или Kotlin, приложение Android, скетч Arduino, bare-metal C для микросхемы AVR, PIC32 или STM32, либо SystemVerilog, Verilog или VHDL для FPGA.

Что умеет программа

Программа — это блоки и связи

Start, Set, Input, Print, If/Else, For, While и Do-While — это блоки, а связи между ними задают порядок выполнения. Нажмите Run, и выполняемый блок подсвечивается. Выражения работают с числами и текстом: && || !, сравнения и обычная арифметика.

Классы, объекты и модули

У класса есть поля с начальными значениями, конструктор и методы, и каждый метод — отдельная блок-схема от Enter до Exit. Каждый Exit становится выходом вызывающего блока. Блоки с одинаковым именем объекта работают с одним объектом. Классы можно сохранить как модули (.eviam) и подключать в другие программы.

Одна схема — девятнадцать языков

Схема говорит, что программа делает, а не на чём она написана. Один и тот же холст превращается в восемь стандартов C и C++, Python 3, Java, Kotlin, приложение Android, скетч Arduino, bare-metal C для AVR, PIC32 или STM32, либо в SystemVerilog, Verilog-2001 и VHDL для FPGA, а Run выполняет саму схему, так что её вывод можно сравнить с любым из них. Если цель не может сохранить блок, ошибка называет этот блок, вместо того чтобы молча менять смысл программы.

Восемь стандартов C и C++ и два стиля кода

Выберите на панели инструментов C99, C11, C17, C++98, C++11, C++14, C++17 или C++20. Structured пишет if/else, циклы и switch; Goto превращает каждый блок в метку, а каждую связь — в переход. Значения Safe хранят текст и сохраняют все проверки интерпретатора; значения Fast — это простые double без проверок во время выполнения. Среда выполнения C содержит только то, что использует программа, поэтому код компилируется без предупреждений с -Wall -Wextra -Wpedantic -Werror.

Python 3 — без компиляции

Выберите Python 3, и та же схема станет одним файлом .py, который работает в Python 3.8 и новее без пакетов и без компилятора. Классы становятся классами Python, а переменные программы — глобальными переменными модуля; Run в окне кода запускает программу, а текст, введённый в Input, передаётся ей. В Python нет goto, поэтому Structured пишет if/else и циклы while, а Goto превращается в небольшой конечный автомат с одной веткой на блок. Print, Input, запись чисел и все сообщения об ошибках — те же, что у интерпретатора.

Код любого блока

Щёлкните блок правой кнопкой и выберите View source code: откроется сгенерированный файл, в котором подсвечены именно те строки, в которые превратился блок. Так же это работает для целого метода или класса, на любом выбранном языке. Compile & Run тут же собирает код с помощью Clang или GCC; в Windows программа сама устанавливает llvm-mingw или WinLibs GCC, Visual Studio не нужна.

Платы Arduino и ESP32

Pin Mode, Digital Write и Read, Analog Read и Write, Delay и Millis — тоже блоки. Один скетч Arduino собирается для Uno, Nano, Mega 2560, Leonardo, Micro и Pro Mini, а также для ESP32, ESP32-S2, -S3, -C3, -C6 и -H2. UART, SPI, I2C и MQTT — тоже блоки. Run имитирует Uno прямо на компьютере и показывает каждое изменение пинов, так что программу можно опробовать ещё до того, как плата окажется на столе.

Без Arduino, прямо на регистрах

AVR C пишет программу для ATmega328P, ATmega2560 или ATmega32U4 без ядра Arduino: порты, таймеры, ШИМ, АЦП и UART настраиваются на понятном C. avr-gcc собирает её примерно в 4 КБ, а Upload загружает на плату через avrdude. Каждый пример запускается в симуляторе simavr и сверяется с интерпретатором.

Новое в 0.5: PIC32 C делает то же для девяти микросхем PIC32MX с Microchip XC32, а UART, SPI и I2C стали блоками, в Run и во всех трёх языках для плат. Код PIC32 проверен по заголовочным файлам Microchip, но ещё не собирался XC32 и не запускался на микросхеме.

Новое в 0.6: поддержка FPGA. SystemVerilog, Verilog-2001 и VHDL превращают ту же схему в аппаратуру для Artix-7 (Nexys A7, Arty A7, Basys 3) и плат Cologne Chip GateMate. Результат моделировался в сравнении с Run и синтезировался открытыми средствами, но не проходил через Vivado и не загружался в плату.

Новое в 0.6.5: MQTT. Пять блоков публикуют числа программы брокеру и читают команды обратно: на PIC32MX с модулем WiFi на UART2, на ESP32 с собственным WiFi и в Run — брокеру на вашем компьютере. Сгенерированный клиент проверяется на настоящем брокере; ни модуля WiFi, ни микросхемы в этой проверке не было. К нему идут два примера, один — для PIC32 Ethernet Starter Kit II. Новое в 0.6.7: MQTT может уходить и через собственный порт Ethernet чипов MX695, MX795 и стартового набора — как приложение для MPLAB X Harmony; это экспериментально и ещё не собиралось с настоящей Harmony. Сам интерфейс тоже теперь на английском, русском или армянском — выбирается в Настройках.

Новое в 0.6.9: Python 3. Та же схема превращается в один файл .py, который работает в Python 3.8 и новее без установки чего-либо ещё, а кнопка Run в окне кода запускает его. Вывод, ошибки и код завершения совпадают с интерпретатором, как у каждого стандарта C и C++.

Новое в 0.7.0: настройки находятся в меню File, по странице на каждое семейство устройств — общие, C, C++ и Python, Arduino, ESP32, AVR C, PIC32 и FPGA, — а в Open Example есть отдельные подменю Arduino, ESP32 и PIC32, которые сразу выбирают нужный язык и плату.

Новое в 0.8.0: установщики приносят инструменты с собой — avr-gcc с avrdude и OSS CAD Suite для FPGA, — поэтому bare-metal C для AVR и маршруты FPGA работают без всякой настройки. Бесплатный XC32 от Microchip устанавливается прямо из приложения (Settings, PIC32, Get XC32) с microchip.com. Settings и Devices теперь отдельные меню.

Новое в 0.7.1: AppImage для любого Linux на x86-64, рядом с .deb — один исполняемый файл с Java внутри, ничего не нужно устанавливать и не нужен root. Модули, доступные программе для платы, описаны выше: UART, SPI, I2C и MQTT.

New in 0.9.0: STM32. The Blue Pill, Black Pill, Nucleo-F401RE, Nucleo-F411RE and STM32F4DISCOVERY take the same diagrams as bare-metal STM32 C (registers only, its own start-up code and linker script) or as Arduino sketches with STMicroelectronics' core, and Upload sends them through an ST-Link with OpenOCD. The installers are now small online installers: the toolchains — arduino-cli, avr-gcc, the Arm GNU Toolchain, OpenOCD and the OSS CAD Suite — are packages of the EVIA server, picked on the first start and updated in place from Settings, Packages and Updates, and the application updates itself the same way. The STM32 code is built with arm-none-eabi-gcc and run in QEMU in CI, but has not yet been run on a board.

Новое в 0.10.0: Java, Kotlin и Android. Та же схема становится программой на Java или Kotlin, которую можно собрать и запустить прямо в окне кода, или приложением Android, которое EVIA Paradigma собирает без Gradle и устанавливает на телефон по USB. JDK и компилятор Kotlin — пакеты сервера EVIA; Android SDK скачивается с сайта Google после того, как вы примете его лицензию.

Новое в 0.10.1: датчики телефона. Блок «Датчик телефона» читает акселерометр, гироскоп и GPS телефона Android, а Run их имитирует. В меню «Файл → Открыть пример → Телефоны Android» есть три готовых приложения: Hello world, просмотр GPS-координат и тест движения.

Новое в 0.11.0: исполняемые программы. Собственный компилятор EVIA Paradigma превращает блоки прямо в программу для Linux x86-64 — без компилятора, ассемблера и компоновщика на компьютере, — и программа ведёт себя точно как Run. EVIA Paradigma Native — второе приложение на его основе: без генерации кода, только «Собрать программу» и «Запустить программу».

Модули, доступные программе для платы

UART передаёт и принимает байты или строки на выбранном порту — именно туда пишет Print на плате. SPI передаёт байт или буфер в режиме master, с выбранными режимом и тактовой частотой и отдельным выводом выбора на каждое устройство. I2C читает и пишет регистры по адресу устройства — так работает большинство датчиков. MQTT — это пять блоков: Connect, Publish, Subscribe, Has Message и Read; они отправляют числа программы брокеру и принимают команды обратно — через WiFi-модуль на UART2, собственный WiFi ESP32 или порт Ethernet чипа PIC32 как приложение Harmony. Каждый модуль — блок в палитре, а не библиотека для установки; в Run он работает так же, как на чипе, а на цели, которая его не поддерживает, отказ называет блок вместо того чтобы собрать код, который молча не заработает.

Проекты, Git и GitHub

File, New Project создаёт папку с программой, папкой модулей, README и Git-репозиторием. Commit, push и pull — в меню Git; Connect to GitHub публикует проект под той учётной записью, которую уже использует ваш git. Программа никогда не запрашивает и не хранит пароль.

  • Vim повсюду. В полях кода, окне кода и сообщениях коммитов работают клавиши Vim; Edit in Vim открывает настоящий Vim.
  • Командная строка. evia --run program.evia и evia --gen program.evia --lang c11 -o program.c для скриптов и Makefile.
  • Python находится сам. Settings, Python использует python3 или лаунчер py в Windows без настройки; Check показывает версию.
  • Clang или GCC. Переключаются в Settings; в Windows любой из них устанавливается сам, Visual Studio не нужна.
  • Тёмная тема. Программа выглядит как IntelliJ IDEA, со шрифтами Inter и JetBrains Mono. View, Theme выбирает светлую, тёмную или системную.
  • Встроенное руководство. Help, Guide (F1) описывает каждый блок, выражения, возможности классов, сочетания клавиш и клавиши Vim, на английском, русском и армянском.
  • Учебник в PDF. Help, Tutorial открывает всё руководство на любом из семи языков.
  • Настройки скачивают инструменты. arduino-cli, avr-gcc и набор для FPGA загружаются в собственную папку приложения; XC32 открывает страницу Microchip.

Первая программа за восемь шагов

Полный пошаговый учебник со всеми снимками экрана доступен в PDF на семи языках: English, Русский, Հայերեն, Deutsch, 简体中文, 繁體中文, 日本語. Он доступен в программе в меню Help, Tutorial и в README.

  1. Создайте проект

    File, New Project. Оставьте отмеченным Create a Git repository.

  2. Соберите цикл

    Перетащите Set, For и Print на холст, соедините их и нажмите Run.

  3. Создайте класс

    Edit, New Class: задайте классу Counter поля total и calls.

  4. Используйте класс

    Перетащите Counter.add(x) в цикл и назовите объект c.

  5. Посмотрите код

    Правый щелчок по блоку, View source code.

  6. Выберите язык

    Переключитесь на C11 или любой стандарт C++, и код сгенерируется заново.

  7. Коммит и публикация

    Git, Commit, затем Connect to GitHub.

  8. Что дальше

    Модули, примеры и руководство (F1).

Ваша первая программа на Python в четыре шага

Любая схема работает как программа на Python. Нужен только Python 3.8 или новее с python.org, а EVIA Paradigma находит его сама.

  1. Выберите Python 3

    Выберите Python 3 в списке Language на панели инструментов или в окне кода.

  2. Создайте код на Python

    Нажмите F7. Щёлкните блок правой кнопкой и выберите View source code, чтобы увидеть, в какие строки он превратился.

  3. Запустите в окне кода

    Нажмите Run. Текст, введённый в Input, передаётся программе, а ошибка останавливает её с тем же сообщением, что и в редакторе.

  4. Сохраните файл .py

    Save записывает файл, и он запускается где угодно командой python3 program.py.

java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang python -o tutorial.py
python3 tutorial.py
# goto flow and fast values work too
java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang python --flow goto --values fast -o tutorial.py

Settings, Python хранит команду: python3, лаунчер py в Windows или полный путь. Detect ищет его заново, а Check показывает версию.

Java, Kotlin и приложения Android за четыре шага

Та же схема становится программой на Java или Kotlin или приложением для телефона Android. Настройки скачивают JDK и компилятор Kotlin одним щелчком, а Android SDK — с сайта Google, после того как вы примете его лицензию.

  1. Выберите Java, Kotlin или Android

    Выберите язык в списке Language на панели инструментов или в окне кода и нажмите F7, чтобы увидеть код.

  2. Соберите и запустите

    Для Java и Kotlin нажмите «Собрать и запустить» в окне кода. Текст, введённый в поле Input, передаётся программе.

  3. Соберите приложение Android

    Кнопка «Собрать» за несколько секунд делает APK собственными инструментами Android SDK, без Gradle и Android Studio. Папку при этом можно открыть и в Android Studio.

  4. Установите его на телефон

    Включите отладку по USB, подключите телефон и нажмите «Установить на телефон». Приложение запустится само: Print — на экране, Input — в текстовом поле.

java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang java -o Program.java
java Program.java
java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang kotlin -o tutorial.kt
java -jar evia-paradigma.jar --android examples/tutorial.evia ~/apps/tutorial --install

В «Настройки → Java и Kotlin» указываются JDK и kotlinc, в «Настройки → Android» — SDK, id и название приложения и телефон. Вывод Java и Kotlin совпадает с интерпретатором в CI; приложения проверены на компьютере, но на телефоне ещё не запускались.

Ваша первая программа для FPGA в четыре шага

Та же схема мигания становится аппаратурой для плат Artix-7 и GateMate. Полное руководство, шаг 10, в PDF выше, а в справке есть раздел про FPGA (F1).

  1. Выберите язык и плату

    Язык: SystemVerilog, Verilog-2001 или VHDL. Плата: Nexys A7, Arty A7, Basys 3 или плата GateMate.

  2. Откройте пример Blink

    Файл, Открыть пример, FPGA Boards, Blink. Выводы задаются именами: LED0, SW3, BTNC, JA1.

  3. Создайте код

    Нажмите F7. Ограничения выводов лежат в первом комментарии, а командная строка записывает их в отдельный файл.

  4. Сборка и загрузка

    Vivado или открытые средства, выбор в Настройках. Загрузка прошивает плату.

java -jar evia-paradigma.jar --gen examples/fpga/blink.evia --lang sv --board nexys-a7-100t -o blink.sv
# writes blink.sv and blink.xdc
java -jar evia-paradigma.jar --gen examples/fpga/blink.evia --lang vhdl --board olimex-gatemate -o blink.vhd
# writes blink.vhd and blink.ccf

Проверено моделированием в сравнении с интерпретатором и синтезом открытыми средствами. Пока не проходило через Vivado и не запускалось на реальной плате.

Скетчи Arduino также собираются для всех 12 плат, включая ESP32 (70 сборок, без предупреждений). Примеры PIC32 компилируются (только синтаксис) по заголовкам Microchip (144 из 144). Каждый пример и тест для FPGA синтезируется yosys для Artix-7, а проекты GateMate размещаются, трассируются и упаковываются в битстримы; Vivado, openXC7 и реальные платы в CI не участвуют. Клиент MQTT собирается на машине сборки и проверяется на настоящем брокере. Плюс проверки приложения, модулей, проектов, Git, масштабирования и перемещения холста в настоящем окне. Подробнее — в GitHub Actions.
