EVIA Paradigma 是一款可视化编程工具，适合想了解机器实际接收内容的人。图表就是程序，语言只是一个设置。在画布上连接程序块并运行，然后选择生成目标：使用 Clang 或 GCC 的 C99 至 C++20、Python 3、Java 或 Kotlin 程序、Android 应用、Arduino 草图、适用于 AVR、PIC32 或 STM32 芯片的裸机 C，或用于 FPGA 的 SystemVerilog、Verilog 或 VHDL。

下载 EVIA 0.12.1 在 GitHub 上查看源代码

支持 Windows、macOS 和 Linux。免费开源，采用 MIT 许可证。

功能介绍

程序由程序块和连线组成

Start、Set、Input、Print、If/Else、For、While 和 Do-While 都是程序块；它们之间的连线表示控制流。按下 Run，正在执行的程序块会高亮显示。表达式支持数字和文本、&& || !、比较运算及常见算术运算。

类、对象和模块

类包含带初始值的字段、构造函数和方法；每个方法都是从 Enter 到 Exit 的独立程序框图。每个 Exit 都会成为调用程序块的输出。使用相同对象名称的程序块共享同一个对象。将类保存为模块（.eviam）并导入其他程序。

一个图表，十九种语言

图表描述程序的功能，而不是它使用的语言。同一画布可生成八种 C 和 C++ 标准、Python 3、Java、Kotlin、Android 应用、Arduino 草图、裸机 AVR、PIC32 或 STM32 C，或用于 FPGA 的 SystemVerilog、Verilog-2001 和 VHDL。Run 会直接执行图表本身，因此你可以将输出与任何生成版本进行比较。如果目标不支持某个程序块，错误会指出该程序块，而不会悄悄改变程序含义。

八种 C 和 C++ 标准，两种编写方式

在工具栏中选择 C99、C11、C17、C++98、C++11、C++14、C++17 或 C++20。Structured 会生成 if/else、循环和 switch；Goto 会将每个程序块转换为标签，并将每条连线转换为跳转。Safe 数值保留文本及解释器的所有检查；Fast 数值是没有运行时检查的普通 double。C 运行时仅包含程序实际使用的部分，因此可通过 -Wall -Wextra -Wpedantic -Werror 严格编译。

Python 3，无需编译

选择 Python 3，同一图表就会生成一个 .py 文件，可在 Python 3.8 或更高版本上运行，无需任何包或编译器。类会变成 Python 类，程序变量会变成模块全局变量；代码窗口中的 Run 会启动程序，在 Input 中输入的文本会传给程序。Python 没有 goto，因此 Structured 会写出 if/else 和 while 循环，Goto 则变成每个程序块一个分支的小型状态机。Print、Input、数字文本以及所有错误消息都与解释器完全一致。

查看任意程序块的代码

右键点击程序块并选择 View source code：生成的文件会打开，并准确高亮该程序块对应的代码行。也可查看整个方法或类，并支持所选的任何语言。Compile & Run 会直接使用 Clang 或 GCC 编译；在 Windows 上，应用会自动安装 llvm-mingw 或 WinLibs GCC，无需 Visual Studio。

Arduino 和 ESP32 开发板

Pin Mode、Digital Write and Read、Analog Read and Write、Delay 和 Millis 也都是程序块。同一个 Arduino 草图可用于 Uno、Nano、Mega 2560、Leonardo、Micro、Pro Mini，以及 ESP32、ESP32-S2、-S3、-C3、-C6 和 -H2。UART、SPI、I2C 和 MQTT 同样是积木。Run 会在电脑上模拟 Uno，并在输出中显示每次引脚变化，让你在接上开发板之前先测试程序。

深入寄存器的裸机编程

AVR C 可为 ATmega328P、ATmega2560 或 ATmega32U4 编写不依赖 Arduino 核心库的程序：使用易读的 C 配置端口、定时器、PWM、ADC 和 UART。avr-gcc 可将程序编译到约 4 KB，Upload 会通过 avrdude 将程序写入开发板。每个示例都会在 simavr 模拟器中运行，并与解释器进行比对。

0.5 新增：PIC32 C 使用 Microchip XC32 为九款 PIC32MX 芯片实现相同功能；UART、SPI 和 I2C 也成为 Run 和全部三种开发板语言中的程序块。PIC32 代码已根据 Microchip 设备头文件检查，但尚未用 XC32 编译或在芯片上运行。

0.6 新增：FPGA 支持。SystemVerilog、Verilog-2001 和 VHDL 可将同一图表转换为适用于 Artix-7（Nexys A7、Arty A7、Basys 3）和 Cologne Chip GateMate 开发板的硬件。输出会与 Run 的结果进行仿真比对，并使用开源工具综合；目前尚未通过 Vivado 或加载到开发板。

0.6.5 新增：MQTT。五个积木把程序的数字发布给代理服务器并读回命令：UART2 接 WiFi 模块的 PIC32MX、自带 WiFi 的 ESP32，以及对着你电脑上代理服务器运行的 Run。生成的客户端对着真实代理服务器检查过，但没有 WiFi 模块或芯片参与。随附两个示例，其中一个用于 PIC32 Ethernet Starter Kit II。0.6.7 新增：在 MX695、MX795 和入门套件上，MQTT 还可以从芯片自带的以太网口出去，生成的文件成为 MPLAB X Harmony 项目的应用程序；这是实验性的，尚未用真正的 Harmony 构建过。界面本身也可在设置中选择英语、俄语或亚美尼亚语。

0.6.9 新增：Python 3。同一图表会生成一个 .py 文件，可在 Python 3.8 或更高版本上运行，无需安装其他内容；代码窗口中的 Run 会直接启动它。其输出、错误和退出码都与解释器一致，和每种 C 与 C++ 标准一样。

0.7.0 新增：设置移到了 File 菜单中，每个设备系列各有一页——常规、C、C++ 和 Python、Arduino、ESP32、AVR C、PIC32 和 FPGA；Open Example 也分成了 Arduino、ESP32 和 PIC32 子菜单，打开示例时会同时选好对应的语言和开发板。

0.8.0 新增：安装包自带工具链——avr-gcc 和 avrdude，以及用于 FPGA 的 OSS CAD Suite——因此裸机 AVR C 和 FPGA 流程无需任何设置即可使用。Microchip 的免费 XC32 可直接在应用中安装（Settings、PIC32、Get XC32），直接从 microchip.com 获取。Settings 和 Devices 现在是独立的菜单。

0.7.1 新增：除 .deb 之外，还有适用于任意 x86-64 Linux 的 AppImage——一个内含 Java 运行时的可执行文件，无需安装，也不需要 root。板上程序可用的模块（UART、SPI、I2C 和 MQTT）在上面有说明。

New in 0.9.0: STM32. The Blue Pill, Black Pill, Nucleo-F401RE, Nucleo-F411RE and STM32F4DISCOVERY take the same diagrams as bare-metal STM32 C (registers only, its own start-up code and linker script) or as Arduino sketches with STMicroelectronics' core, and Upload sends them through an ST-Link with OpenOCD. The installers are now small online installers: the toolchains — arduino-cli, avr-gcc, the Arm GNU Toolchain, OpenOCD and the OSS CAD Suite — are packages of the EVIA server, picked on the first start and updated in place from Settings, Packages and Updates, and the application updates itself the same way. The STM32 code is built with arm-none-eabi-gcc and run in QEMU in CI, but has not yet been run on a board.

0.10.0 新增：Java、Kotlin 和 Android。同一图表可生成 Java 或 Kotlin 程序，直接在代码窗口中编译运行；也可生成 Android 应用，EVIA Paradigma 无需 Gradle 即可构建，并通过 USB 安装到手机上。JDK 和 Kotlin 编译器是 EVIA 服务器的软件包；Android SDK 在你接受其许可证后从 Google 下载。

0.10.1 新增：手机传感器。Phone Sensor 程序块可读取 Android 手机的加速度计、陀螺仪和 GPS，Run 会模拟它们。File → Open Example → Android Phones 中有三个入门应用：Hello world、GPS 坐标查看器和运动测试器。

0.11.0 新增：原生可执行程序。EVIA Paradigma 自带的编译器可将程序块直接转换为 Linux x86-64 程序，电脑上无需编译器、汇编器或链接器，程序的行为与 Run 完全一致。EVIA Paradigma Native 是基于它的第二个应用：不生成代码，只有 Build executable 和 Run executable。

板上程序可用的模块

UART 在所选端口上收发字节或整行，在板上也是 Print 的输出去处。SPI 以主机方式传输一个字节或一段缓冲区，模式和时钟由你选择，每个设备可指定各自的片选引脚。I2C 按设备地址读写寄存器，大多数传感器就是这样驱动的。MQTT 是五个块——Connect、Publish、Subscribe、Has Message、Read——把程序的数值发到代理并取回命令，走 UART2 上的 WiFi 模块、ESP32 自带的 WiFi，或 PIC32 自己的以太网口（作为 Harmony 应用程序）。每个模块都是调色板里的一个块，而不是需要安装的库；在 Run 中与在芯片上行为一致；在不支持它的目标上会指名拒绝，而不是生成一段默默无法工作的代码。

项目、Git 和 GitHub

File, New Project 会创建一个包含程序、模块文件夹、README 和 Git 仓库的文件夹。Git 菜单中可执行 Commit、push 和 pull；Connect to GitHub 会使用 Git 已有的登录信息发布项目。应用不会索要或保存密码。

  • 随处使用 Vim。代码字段、代码窗口和提交消息均支持 Vim 按键；Edit in Vim 会打开真正的 Vim。
  • 命令行。 evia --run program.evia 和 evia --gen program.evia --lang c11 -o program.c 可用于脚本和 Makefile。
  • 自动找到 Python。 Settings, Python 无需设置即可使用 python3 或 Windows 上的 py 启动器；Check 会显示版本。
  • Clang 或 GCC。可在 Settings 中切换；Windows 会自动安装所选编译器，无需 Visual Studio。
  • 深色模式。应用采用类似 IntelliJ IDEA 的外观，并使用 Inter 和 JetBrains Mono 字体。View、Theme 可选择浅色、深色或系统主题。
  • 内置指南。Help、Guide（F1）提供英语、俄语和亚美尼亚语版本，说明各程序块、表达式、类功能、快捷键和 Vim 按键。
  • PDF 教程。 Help, Tutorial 可用七种语言中的任意一种打开完整教程。
  • 设置会下载工具。 arduino-cli、avr-gcc 和 FPGA 套件会下载到应用自己的文件夹；XC32 会打开 Microchip 的页面。

八步完成第一个程序

完整教程包含所有截图，提供七种语言的 PDF：English、Русский、Հայերեն、Deutsch、简体中文、繁體中文、日本語。也可在应用的 Help、Tutorial 中查看，或阅读 README。

  1. 创建项目

    File、New Project。保持选中 Create a Git repository。

  2. 构建循环

    将 Set、For 和 Print 拖到画布上，连接它们并按 Run。

  3. 创建类

    Edit、New Class：为 Counter 添加 total 和 calls 字段。

  4. 使用类

    将 Counter.add(x) 拖入循环，并将对象命名为 c。

  5. 查看代码

    右键点击程序块并选择 View source code。

  6. 选择语言

    切换到 C11 或任意 C++ 标准，代码会重新生成。

  7. 提交并发布

    选择 Git、Commit，然后选择 Connect to GitHub。

  8. 继续探索

    模块、示例和指南（F1）。

四步完成第一个 Python 程序

任何图表都能作为 Python 运行。只需要来自 python.org 的 Python 3.8 或更高版本，EVIA Paradigma 会自动找到它。

  1. 选择 Python 3

    在工具栏或代码窗口的 Language 列表中选择 Python 3。

  2. 生成 Python 代码

    按 F7。右键单击程序块并选择 View source code，即可查看它生成的代码行。

  3. 在代码窗口中运行

    按 Run。在 Input 中输入的文本会传给程序，出错时程序会停止，并显示与编辑器中相同的消息。

  4. 保存 .py 文件

    Save 会写出该文件，它可以在任何地方用 python3 program.py 运行。

java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang python -o tutorial.py
python3 tutorial.py
# goto flow and fast values work too
java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang python --flow goto --values fast -o tutorial.py

Settings, Python 中保存运行命令：python3、Windows 上的 py 启动器或完整路径。Detect 会重新查找，Check 会显示版本。

四步完成 Java、Kotlin 和 Android 应用

同一图表可以生成 Java 或 Kotlin 程序，也可以生成 Android 手机应用。设置中一键即可获取 JDK 和 Kotlin 编译器；接受许可证后，Android SDK 会从 Google 下载。

  1. 选择 Java、Kotlin 或 Android

    在工具栏或代码窗口的 Language 列表中选择，然后按 F7 查看代码。

  2. 编译并运行

    对于 Java 和 Kotlin，在代码窗口中按 Compile & Run。在 Input 中输入的文字会传给程序。

  3. 构建 Android 应用

    Build 使用 Android SDK 自带的工具在几秒内生成 APK，无需 Gradle 或 Android Studio。该文件夹仍可在 Android Studio 中打开。

  4. 安装到手机

    打开 USB 调试，连接手机并按 Install on Phone。应用会自动启动：Print 显示在屏幕上，Input 在文本框中输入。

java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang java -o Program.java
java Program.java
java -jar evia-paradigma.jar --gen examples/tutorial.evia --lang kotlin -o tutorial.kt
java -jar evia-paradigma.jar --android examples/tutorial.evia ~/apps/tutorial --install

Settings 的 Java and Kotlin 页面设置 JDK 和 kotlinc；Android 页面设置 SDK、应用的 ID 和名称以及手机。Java 和 Kotlin 的输出在 CI 中与解释器一致；应用已在电脑上检查，但尚未在手机上运行过。

四步完成第一个 FPGA 程序

同一个 blink 图表可转换为适用于 Artix-7 和 GateMate 开发板的硬件。完整教程的第 10 步见上方 PDF，指南中也有 FPGA 主题（F1）。

  1. 选择语言和开发板

    语言：SystemVerilog、Verilog-2001 或 VHDL。开发板：Nexys A7、Arty A7、Basys 3 或 GateMate。

  2. 打开 Blink 示例

    File、Open Example、FPGA Boards、Blink。引脚名称示例：LED0、SW3、BTNC 和 JA1。

  3. 生成代码

    按 F7。引脚约束位于第一条注释中，命令行会将其写入单独的文件。

  4. 构建并上传

    在 Settings 中选择 Vivado 或开源工具。Upload 会对开发板进行编程。

java -jar evia-paradigma.jar --gen examples/fpga/blink.evia --lang sv --board nexys-a7-100t -o blink.sv
# writes blink.sv and blink.xdc
java -jar evia-paradigma.jar --gen examples/fpga/blink.evia --lang vhdl --board olimex-gatemate -o blink.vhd
# writes blink.vhd and blink.ccf

已在仿真中与解释器比对，并使用开源工具综合。尚未通过 Vivado 运行或加载到真实开发板。
